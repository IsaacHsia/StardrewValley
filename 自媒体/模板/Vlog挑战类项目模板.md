# 🎯 Vlog 挑战类项目模板

> 适用类型：社交/街头挑战 · 技能学习挑战 · 自我实验类
> 发布平台：抖音 + 小红书（长短视频）
> 制作频率：年更 150 期 ≈ 每周 3 条
>
> **本模板 7 个阶段覆盖一条挑战视频从策划到复盘的完整流程。**
> 三类挑战的差异用 `📌 社交 / 📌 技能 / 📌 实验` 标注，长短视频用 `▸ 短视频版 / ▸ 中长视频版` 区分。
>
> 关联文件：[[Hero_Vlog不可控场景清单]]（纪实类补充工具）

---

## Phase 4：现场拍摄清单 🎥

> 根据 [[Hero_Vlog不可控场景清单]] 的清单逻辑改编，聚焦挑战类核心镜头。

### 必须拍到

```
□ 挑战开始前的"出发"状态（信心 / 紧张 / 对话）
□ 挑战规则交代（口述 + 画面辅助）
□ 挑战过程中的关键节点（每个转折点）
□ 结果揭晓瞬间（成功 / 失败 / 意外）
□ 主演的真实反应（近景 / 特写）
□ 团队 / 对手 / 路人的反应（如有）
□ 挑战结束后的状态对比（累 / 兴奋 / 沮丧）
```

### 加分拍到

```
□ 过程意外的反转
□ 对手 / 队友的即时反应
□ 细节特写（手、表情、道具变化、计时器）
□ 时间流逝的视觉标志（天色 / 计时器 / 进度条）
□ 📌 社交类：路人的真实反应和对话
□ 📌 技能类：从生疏到熟练的进步轨迹
□ 📌 实验类：过程中身体/情绪的变化细节
```

### 一定要有的 B-roll

```
□ 场景空镜（15-30 秒）
□ 道具 / 物件的多角度特写
□ 环境声（30 秒纯声，到场和离场各录一次）
□ 转场镜头（进门 / 出发 / 走路 / 开车 / 上下楼）
□ 地标 / 路牌 / 店名
```
