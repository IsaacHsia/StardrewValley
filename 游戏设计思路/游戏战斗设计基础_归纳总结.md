## 一、战斗策划的素养与思维

> 来源：战斗设计基础（一）

### 1.1 系统策划的四级分层

| 级别     | 特点                                                    |
| :----- | :---------------------------------------------------- |
| **初级** | 仅擅长设计单一系统                                             |
| **中级** | 擅长设计单一系统，主要精力在优化界面，界面浮夸，满嘴"按钮位置""界面大小""加个特效"          |
| **高级** | 擅长做系统框架，注重系统间关联，有清晰的数值认知和成长体验认知，主张**界面极简主义**          |
| **资深** | 在高级基础上最重要的一点——**回归游戏本真**，能回忆起入行前对游戏最原始的乐趣体验，"带着修为往回走" |

### 1.2 战斗策划的核心思维

- **思维必须完全反人性**：玩家想的是"如何玩好战斗"，策划要想的是"如何设计体系让玩家有兴趣、有欲望、有途径、有方法把战斗玩好"
- **系统功能要加持战斗功能**：战斗策划的思维范围不仅包括技能搭配、地图策略，还要涵盖系统功能对战斗的支撑
- **以《英雄联盟》为例**的推演思维：
  - 为什么3路配比是1-1-2？→ 谁需要成长谁走单路，谁能压制谁去对路
  - 小龙为什么在右下方？→ 为了让辅助可以分身帮打野打小龙
- **任何成熟战斗体系的搭建，都是上线后漫长的优化和迭代过程**

### 1.3 关键设计教训

- **伤害来源要直观**：玩家最直观的感受是图形变化和个体差异，不是数字
- **付费后体验不能变弱**：如果付费提升等级后打BOSS反而更吃力（打不动），就是设计失误
- **修改方案要系统性思考**：例如将绑定在角色上的"大刀系统"改为"宠物"，让伤害来源直观化

## 二、武器设计的四大要素

> 来源：战斗设计基础（二）——《战神4》武器篇

### 2.1 策略性和趣味性

- 一把武器应当赋予玩家**策略选择的空间**
- 《战神4》利维坦战斧的投掷与召回机制：
  - 投掷可远程打击敌人、冻住冲来的近战敌人
  - 召回时机是关键策略：留斧冻敌专心空拳战斗？还是召回打出背击？
  - 斧头飞回路径经过敌人可造成伤害，精准投掷连招可触发冰冻伤害
  - 配合"背叛护身符"的慢时间瞄准，乐趣在于抓住最佳时机

### 2.2 易用性

- **为单一熟悉的机制赋予多种不同用途**，让玩家更容易上手
- 玩家只需一把斧子即可完成战斗、探索、解密等多重交互
- **反面教材**：《Warframe》武器复杂多变的属性虽有深度，但易用性差，新手越来越难上手

### 2.3 多用性

- 围绕易用性主体展开各种用途，形成多用性
- 战斧在战斗之外的用途：转动轮盘、击落篮子、冰冻陷阱、打掉渡鸦
- **武器理解难易度**是关键：复杂武器也可形成多用性，但理解成本高

### 2.4 出色的手感

- **击中暂停/放慢**：动作在击中敌人时暂停0.5秒增强打击感
- **砍入感**：斧子砍入敌人身体卡几帧，随后从身上移开跟上动作，表现"确确实实砍入了身体"
- **不同部位不同反馈**：砍中头部/腿部/身体有不同受击动作、声效、手柄震动
- **召回的分量感**：
  - 斧子从物体表面微微摆动0.5秒 → 确实砍入了
  - 按弧线返回，距离越远飞回越快
  - 接住时主角胳膊微微颤动+震屏
  - 手柄震动随距离加快

## 三、逐帧分析：从实现层面理解战斗

> 来源：战斗设计基础（三）&（四）——《黑神话：悟空》逐帧讲解

### 3.1 技术实现要点

| 技术 | 说明 |
|:---|:---|
| **复合碰撞体** | 小怪按关节划分碰撞体，打击盒碰到哪个部位就在哪里产生受击特效 |
| **运动学刚体碰撞体** | 武器落地使用，与击飞物件技术一致 |
| **Physic Material Bounciness** | 舞棒抵挡远程攻击时，箭支打中圆面被弹开 |
| **范围触发** | 角色走到范围内触发事件（变身、遇NPC等） |
| **镜头锁定** | 镜头始终盯着目标，自动转向 |
| **LOD层级** | 远近切换材质清晰度，需优化层级间差距 |
| **3D声效** | Spatial Blend=1，声音近大远小 |

### 3.2 打击感实现方法对比

| 方法 | 适用场景 | 举例 |
|:---|:---|:---|
| **击中暂停/放慢** | 不能砍入身体的武器（棍棒类） | 《黑神话：悟空》棍子攻击 |
| **卡帧砍入** | 能深深砍入身体的武器（斧头类） | 《战神4》战斧劈砍 |
| **撑杆静止4帧** | 蓄力重击 | 棍子变到最大时静止再下打 |

### 3.3 关键设计问题

- **受击方向不一致**：说明只做了几个受击动作，没有按受击方向制作匹配动作
- **格挡特效位置错误**：侧面攻击的格挡特效播放在正中间，没做位置适配
- **Boss无部位生命**：轰龙是整体生命体，砍哪里效果都一样，至少应做"一瘸一拐"
- **变身技能过强**：伤害高+群攻+控制+血厚，缺乏前置触发条件
- **加速跑与慢跑不做速度过渡**：做了之后战斗中产生策略误差，体验不好

### 3.4 怪物AI要素

1. **状态判定**：闲逛、战斗、巡逻等状态切换
2. **寻路逻辑**：当前朝向/目标朝向、最短路线、可翻越障碍、移动障碍、技能寻路
3. **碰撞处理**：释放技能时关闭碰撞体
4. **技能释放判定**：有些只需判定直线距离，有些需判定最短行军距离

## 四、从零开始设计一款动作游戏

> 来源：游戏战斗设计基础（五）——从0开始的动作游戏

### 4.1 设计流程

```
选题 → 确定游戏类型 → 叙事设计 → 装备设计 → 属性与机制设计 → 战斗公式 → 关卡设计
```

### 4.2 各环节要点

**选题**：选题确定可行方向，方向对了项目就成功一半。要验证数据形成用户画像，评估团队实力和市场可行性。

**确定游戏类型**：从大品类（如ACT）中摘取与玩法匹配的元素融合，标记需要突出和增强的部分。

**叙事设计**：
- 确定主角为什么而战
- 设计时间线和事件
- 事件中的环境是关卡设计的前提
- 叙事比重决定游戏偏向剧情还是偏向打斗

**装备设计**（四大要素的应用）：
1. 头脑风暴列举武器能力
2. 按策略性/趣味性、易用性/多用性、出色手感分类
3. 出现在多个要素下的能力优先制作（如"击晕敌人"）
4. 武器设计应覆盖攻防两端

**属性设计原则**：
- 属性应遵循**有趣、易懂、差异化、表现明显**
- 动作游戏把操作正确与否当掷骰子：操作正确得奖励，操作错误受惩罚
- 概率性闪避在动作游戏中体验差（"操作概率×数值概率=命中"会降低操作奖励感）
- 移除无趣的属性（如《魔兽世界》移除了"抗性"）

**机制设计**：
- 出发点：操作正确后获得奖励
- 先考虑操作是否有趣，再考虑奖励是否顺理成章
- 翻滚 vs 格挡：翻滚打断进攻连续性，格挡成功后获得攻击加成更优
- 挡刀优于翻滚：《只狼》用挡刀防御，攻防切换更连贯

**战斗公式设计**：
- 让属性价值真实反映在数值结果上
- 让玩家清晰理解属性与伤害的线性/非线性关系
- 将期望效果逐步融入公式：基础减法 → 加入元素 → 加入暴击 → 加入格挡

**关卡设计**：
- 与故事主线融入，降低学习难度
- 划分关卡章节，加标签标记情景内容、机关、怪物
- 剧本顺序可倒叙、穿插
- 商业化关卡：前部分实力验证，后部分BOSS挑战

## 五、关卡中的资源投放设计

> 来源：游戏战斗设计基础（六）——Roguelike关卡里的箱子

### 5.1 宝箱的两层设计含义

| 层次 | 含义 |
|:---|:---|
| **目标层** | 以探索整张关卡地图为目标，引导玩家探索每个角落 |
| **手段层** | 以稀有的惊喜奖励为手段，激发玩家行动欲望 |

### 5.2 碎桶体验设计

**两个核心问题**：
1. **玩家用什么方式打碎木桶** → 决定操作体验
2. **木桶怎么分布** → 决定分布体验

| 游戏 | 打碎方式 | 分布方式 | 体验 |
|:---|:---|:---|:---|
| 《龙之谷》 | 技能（耗蓝）vs 普攻（单目标） | 集中分布 | 部分职业体验糟糕 |
| 《地下城与勇士》 | 滑铲（无消耗） | 集中分布 | 一排铲碎，体验顺畅 |
| 《Warframe》 | 爆炸机制连锁碎箱 | 松散分布 | 利用规则创造乐趣 |

### 5.3 关键洞察：关卡进入成本决定碎箱意愿

- **高进入成本**（如《地下城与勇士》疲劳值）→ 每种资源都是稀缺的 → 玩家必须打碎每一个桶
- **零进入成本**（如《Warframe》常规关卡）→ 玩家觉得可以下次再打 → 顺手的打，不顺手的不打
- 即使增加稀有掉落也无法解决零成本关卡的碎箱意愿问题

## 六、程序化生成：算法驱动的地图设计

> 来源：游戏战斗设计基础（七）——用算法生成《率土之滨》的世界地图

### 6.1 算法要实现的五大目标

1. **固定位置模块**：城市、关隘等固定区域和连接点
2. **区域边缘处理**：避免边界出现大面积不可通行区域
3. **地图模块种类均衡**：高等级资源分布稀疏，同级资源地区均衡
4. **玩家资源平衡**：初始坐标附近资源数量和距离均衡
5. **玩家地区密度**：避免密度过大导致前期PVP过频

### 6.2 算法层架构

```
成像层 → 生成地貌参数（Perlin噪声）
承载层 → 地格层 / 地表基色层 / 资源和不可通行层 / 怪物层
```

### 6.3 关键算法

| 用途 | 算法 |
|:---|:---|
| 基本轮廓生成 | **Perlin噪声**（多振幅频率叠加） |
| 孤岛陆地生成 | **种子生长** |
| 地形定义 | 高度值划分：Z≥2山脉、0<Z<2资源、Z≤0河流 |
| 区域边缘延伸 | 随机值0-3加权，控制山脉或可通行区域比例 |
| 固定点保护 | 控制区域内网格点向量角度，避免高低起伏 |
| "回"字型区域检测 | **广度优先搜索**判断路径可达性 |
| "桶"型区域检测 | 连续点距离关键点距离差分析 |
| 资源均衡分布 | **米切尔最佳候选算法**（近似泊松圆盘） |
| 玩家初始位置 | 5格最小间距 + 周围资源均衡采样 |

## 七、情感：战斗设计的终极目标

> 来源：游戏战斗设计基础（八）——终极目标：情感

### 7.1 核心论点

- **游戏机制**是引导游戏运行的规则（按下按键A让马里奥跳起来）
- **事件**是游戏过程中发生的某件事情
- **事件必须激发某种情感才有意义**
- **情感是终极目标**：玩家说游戏"好玩"或"不好玩"，背后真正驱动作结论的是情感体验

### 7.2 情感设计原则

- 好游戏产生的事件需要能够激发**自豪、欢乐、恐惧、紧张**等情感
- 游戏设计师必须像厨师品尝菜肴、音乐家分辨和弦一样，**感知转瞬即逝的情绪**
- 游戏中的一切机制和事件，最终都应服务于情感体验

### 7.3 情感体验案例

- 《魔兽世界》被野怪击杀 → 失望、咬牙切齿
- 跑尸体过程 → 无聊，多次后可能愤怒关掉游戏
- 击败敌对玩家 → 自豪与喜悦
- 焦虑等待对手出招 → 肾上腺素飙升、心跳加快

## 八、战斗平衡的数学基础

> 来源：战斗设计基础（九）——战斗平衡的数学基础

### 8.1 必修三大学科

| 学科 | 应用场景 |
|:---|:---|
| **概率论** | 用到最多：暴击、闪避、命中、抽卡概率分布、正态分布 |
| **线性代数与空间解析几何** | 多兵种对战的矩阵表达、行列式计算 |
| **微积分** | 战损计算、兰彻斯特方程、积分/偏积分 |

> 三门学科同等重要，没有主次，必须同步学习。

### 8.2 概率论的核心问题

- **10%抽卡概率**≠玩家10次抽出1张：实际是长尾分布，有的几次就出，有的300次不出
- 需要用**正态分布**来控制期望分布
- 暴击、闪避、命中等属性触发都需要概率论
- 技能效果（"30%概率沉默"）的触发也涉及概率分布

### 8.3 战损计算

- 先手影响、兵力差异、秒伤差异 → 需要**行列式、积分、偏积分**
- **兰彻斯特方程**需要三门数学都能看懂

### 8.4 实用建议

- 系统数值（高中数学）≠ 战斗数值平衡（大学数学），数学思维上略有优势但工具上差异大
- 做战斗可以不做数值，但大部分厂商也招不到数学好的数值策划
- 传奇/仙侠类游戏很少用到高等数学，初高中数学即可

## 九、魂系ACT攻防机制推导

> 来源：游戏战斗设计基础（十一）——魂系ACT游戏的战斗机制设计

### 9.1 从最简对局到策略攻防

**起点**：AB两单位仅有血量、攻击、100%命中 → 先手必胜，毫无悬念

**逐步引入机制**：

| 步骤 | 引入机制 | 解决的问题 |
|:---|:---|:---|
| 1 | 举盾防御 | 降低先手优势，但防御方无进攻意愿 |
| 2 | 动作三段式（前摇/生效/后摇） | 让防御方可以观察和判断 |
| 3 | 防御使用限制（能量消耗） | 促使攻防互换 |
| 4 | 高风险高收益机制 | 创造变数，使防御/进攻有失效机会 |

### 9.2 动作三段式划分

**攻击动作**：
- **前摇**：挥砍开始到砍到对方（信息提示，可被观察）
- **生效**：砍到对方到开始收刀（造成伤害）
- **后摇**：开始收刀到恢复待机

**防御动作**：
- **前摇**：举盾开始到完全举起
- **生效**：盾牌完全举起到收盾（持续防御能力）
- **后摇**：开始收盾到恢复待机

### 9.3 核心攻防机制体系

| 机制 | 能量消耗 | 特点 |
|:---|:---|:---|
| **轻击** | 10 | 前摇短，伤害低，击中未防御目标使其僵直 |
| **重击** | 15 | 前摇长，伤害高，无视盾防，免疫轻击僵直 |
| **盾防** | 8（被击中时） | 抵消100%伤害，来自正面100° |
| **盾反** | 15 | 瞬间弹开攻击，成功防重击使对方僵直 |
| **翻滚** | 15 | 向移动方向位移，动作短于重击前摇 |

### 9.4 克制关系图

```
盾防 → 克制 → 轻击
轻击 → 克制 → 盾反
盾反 → 克制 → 重击
重击 → 克制 → 盾防
```

> **核心原则**：任何攻击都有防御克制，任何防御都有攻击克制 → 策略性战斗（"魂味"）

### 9.5 僵直机制的质变

- **连击**：A击中B打出僵直，A在B僵直结束前再次攻击 → B持续僵直
- **反击**：B僵直结束时存在前摇比任何防御都短的攻击机制 → B可反击使A僵直

### 9.6 职业划分带来的新机制

**双持职业（无盾牌）**：
- 更高攻击力 + 更高被伤害风险
- 引入**翻滚**：需同时引入移动、转向、指向性攻击、攻击范围
- 翻滚是否无敌取决于：位移长度、怪物技能设计、前摇时长、方向判定时机

**远程职业**（思考题）：
- 距离优势 = 追击时间内的免费输出
- 必须引入**加速跑**
- 输出时必须**降低移速或不能移动**
- 近战伤害必须高于远程，或血量高于远程

## 十、数值框架搭建与战斗平衡计算

> 来源：游戏战斗设计基础（十二）——数值框架搭建及战斗平衡计算实践

### 10.1 数值设计的四个前提

1. **数值不是万能的**，先有需求再有数值
2. **数值设定需有法可依**（如LOL初始金币500是为了充分利用出门装）
3. **数值设定需要机制配合**（如暴击伪随机：递增概率法）
4. **数值设定不一定见效**（如《艾尔登法环》死亡掉金币，玩家学会刷光金币进副本使惩罚失效）

### 10.2 暴击率伪随机方案

| 方案 | 方法 |
|:---|:---|
| **方案一** | 1-10随机排布，≤3暴击，砍完10刀重新排序 |
| **方案二** | 第一刀11.89%暴击率，未暴击则下一刀翻倍（23.78%），暴击后重置，总体维持30% |

### 10.3 基础概念

- **回合**：一方进行一次攻击结算的最小时间单位
- **战斗总回合数**：衡量职业平衡的标准
- **数学期望**：期望值 = Σ(概率 × 数据)
- **体验设定数据**：与体验直接相关的数值，是**自变量**
- **技能冷却计算**：取决于冷却起点（前摇开始/前摇结束/后摇结束）
- **最大值和最小值**：用于计算和调节不稳定数据（BUFF享受时长）

### 10.4 数值框架搭建流程

```
定义属性及公式 → 定义标准人物属性 → 定义装备属性 → 分配装备类型和属性
→ 设定职业及属性 → 各职业装备属性 → 属性汇总 → 设定职业技能
→ 职业对抗及数值平衡计算
```

### 10.5 职业对抗平衡验证

- **模拟条件**：不同等级（10/20/30）、不同品质装备
- **平衡标准**：前一秒双方"生命/总伤害">1，下一秒都<1
- **追击公式**：X = M/(A-B)，A追方速度，B被追方速度，M初始距离
- **允许小误差**，实际操作误差可覆盖；大误差需调整装备属性
- **分段函数**是数值策划常用工具，方便调节和拓展

### 10.6 商业模型应用

- 根据流量、付费率、大R/中R/小R比例 → 推算各层级年付费期望
- 决定付费深度和充值档位定价

## 核心设计原则速查

1. **先需求后数值** — 数值是调整体验的工具，不是设计的起点
2. **操作正确给奖励，操作错误给惩罚** — 动作游戏的核心逻辑
3. **任何攻击都有防御克制，任何防御都有攻击克制** — 策略性的根基
4. **武器设计四要素** — 策略性/趣味性、易用性、多用性、出色手感
5. **动作三段式** — 前摇/生效/后摇，信息可观察是策略的前提
6. **概率性属性在动作游戏中体验差** — 闪避等概率属性会削弱操作奖励感
7. **翻滚打断进攻连续性，格挡更优** — 攻防切换的连贯性
8. **关卡进入成本决定资源收集意愿** — 疲劳值 vs 零成本
9. **情感是终极目标** — 机制和事件都应服务于情感体验
10. **战斗平衡需要大学数学** — 概率论、线性代数、微积分同等重要
