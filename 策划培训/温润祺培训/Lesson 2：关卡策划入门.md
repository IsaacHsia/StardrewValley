# Part 1. 作业分析

## 想加入的游戏类型
### 1. 开放大世界
原因：
1. 社交功能
2. 模拟经营
3. 大世界地图设计
4. 大世界玩法设计
### 2. 3DRPG ⭐️
原因：
1. 空间探索
2. 空间&角色叙事

## 游戏拆解
进步点：
- **空间结构设计**：识别"假开放真线性"（高台/悬崖锁路线）、垂直分层探索（上下层+隐藏地板）
- **引导设计**：区分明引导（草丛/陷阱/铃铛教学点）与暗引导
- **探索节奏**：单向门/竖井/捷径解锁、"即使有地图也会迷路"的不确定性设计
- **难度曲线**：自发归纳出教学-变招-熟练-Boss的节奏模型
- **能力门控：能力锁→新区域（钩索/潜水/滑翔伞）的银河城关卡探索的核心逻辑
优化点：
- 分析偏"**逐点描述**"，缺**设计原则的归纳**（为什么这样设计、可复用的法则是什么）
- 未建立标准关卡设计文档（LDD）的字段意识，文档结构需要继续优化：帮助读者了解这款游戏&理解你是如何理解游戏设计的
- 缺**量化语言**：如"前X分钟教学、敌人密度每X米一个"，让设计可被评估

# Part 2. 单机策划 vs 商业化手游策划
## 运营模式区别
- 商业游戏（服务型游戏gaas)：长期运营，用户付费，数据驱动——产品上限为起点
- 单机买断制游戏：一次性买断、靠内容口碑、作者驱动——上线作为终点
## 对比

| 维度       | 商业化游戏                      | 单机游戏                          |
| -------- | -------------------------- | ----------------------------- |
| 待遇       | 起薪较高、旱涝保收、定时分红             | 起薪较低、回报后置                     |
| 现金流      | 上线回收快                      | 相对不稳定，研发期长依赖稳定投产              |
| 岗位数量     | 极多（95%+）                   | 少数团队                          |
| 对应届生/跨专业 | 校招通道较多                     | 保守，经验要求高                      |
| 成长方向     | 方法论+数据导向                   | 设计内容导向                        |
| 风险       | 作为起点，如果缺少亮眼项目经历，后续转向单机游戏较难 | 门槛较高，如果不是头部团队项目风险较高，研发期待遇相对较差 |


# Part 3. 关卡策划所需作品集一般包含内容

## 关卡作品
### 1. 关卡白盒（最好可玩）
5-10分钟可玩，包含
- 空间概念
	- 地图结构
	- 动线垂直分层
	- 捷径/回路
	- 地标布置
- 玩家动线
- 游戏引导
- 玩法展示
- 探索节奏
### 2. 关卡内的简单交互逻辑（加分项）
触发器、开门、能力门控（钥匙、解谜）

### 3. 难度曲线设计
教学-解题-组合-考验
战斗-解谜-修整的节奏

### 4. 怪物、事件布局
体现遭遇设计与战斗节奏意图

### 5. 环境叙事
场景/道具/布局讲故事，关卡与世界观/角色背景融合


## 设计文档与表达

### 1. 规范的关卡设计文档
设计目标、空间结构、动线、引导、节奏

### 2. 关卡平面图与动线图
标注路径/地表等关键位置

### 3. 设计思路
用专业方式表达设计内容

### 4. 设计草稿
1. 目标：为什么设计关卡
2. 主题：这个关卡的主题（逃脱/暗杀/…）
3. 元素：能用来做关卡并完成目标的内容
*联合军警察、士兵
*猎头蟹
*友好NPC（拯救，一起战斗，治疗）
爆炸物
载具
直升机
武器
4. 关卡流程：最重要的，一定要出现在关卡中的（可以按照预想的流程进行排序）——注意长期目标与短期目标的结合；关注设计案里面的逻辑性，而不是空间感和视觉性布局，这个可以之后再考虑
