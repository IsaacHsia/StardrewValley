#  长红线
![[Pasted image 20260528231555.png]]
1. 低档长红：经过较长（5-10个交易日）或较深跌幅（个股10%，指数5%）之后，出现的显著长红，切当日成交量显著高于前几日的平均成交量，大资金入场启动买入信号
2. 高档长红：多头耗尽警告
3. 长红突破（翻箱体）：在一段时间内的箱体碰撞之后，出现一根长红，放量是真，缩量是假。翻箱之后长多高：箱体上线+（箱体上线-箱体下线）
4. 长红跌破：大量的止损盘启动和加速下跌开始。长红线的中间值跌破就要考虑减仓，最低点考虑清仓

# 长黑线
开盘价=当日最高价
收盘价=当日最低价，上下引线基本没有
高档长黑遇到直接清仓
低档长黑，考虑是非是非理性下跌，接近底部
高档长黑哪怕没有放量，也要清仓，卖盘不重都没有人接了

# 上吊线
长上影线=市场上尝试过把价格推高，失败了
长下影线=市场尝试把价格压低但是失败了
上吊线=高位时候，实体部分很小，上影线非常短，下影线很长，可以是实体的2-3倍
代表着，经历一段时间的上涨后，空方突然进攻价格达到了日内最低，但是收盘前买盘把价格救了回来；多方掌控的局面开始发生了松动。第二天确认是否继续了不好的趋势，如果有就果断减仓30%-50%

# 铁锤线
和上吊线一致，区别在于出现在低位

# 流星线
实体部分很小，上影线非常长，下影线很短，上影线可以是实体的2-3倍
代表着，经历长时间上涨后，多方继续进攻，价格倍推到了日内大幅高于开盘价的位置，在最高点遇到卖盘，价格被压回收盘附近；多方进攻最后的尝试结束了
化解条件：第二天高开高走，且站上了流星线的最高点
上影线化解压力会比下影线更难，减仓的幅度需要更大
流星线隔天没化解，第三天大阴线——确认见顶

# 倒装铁锤线
和流星线一样，区别在于出现在低位，多方开始有了进攻能力
