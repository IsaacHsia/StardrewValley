# 一、盘面定性：连续杀跌后的情绪共振拐点

三大指数探底回升集体收红，创业板指盘中一度跌超1%、最终涨近2%，是典型的"先杀后拉"V型修复。沪深成交2.97万亿、缩量2704亿，超3000只个股上涨、过百股涨停——量能收缩但赚钱效应放大，这是修复行情而非放量进攻的特征。

定性上有三层判断需要锁定：

第一，**这是连续杀跌之后的阳线共振**，不是趋势中继。从先手视角，它的意义是"情绪拐点"，而不是"主升确认"。把它当拐点对待，意味着仓位与节奏要按"右侧第一根"处理，而非追高。

第二，**修复的形态是"普涨式轮动"而非"主线引领"**。今天科技几乎把自己的所有分支都轮了一遍：从电容/MLCC、培育钻石(金刚石)，到电子布(CCL)、磷化铟、薄膜铌酸锂，再到CPO、PCB、半导体制造。问题恰恰在这里——**轮动越全面，越说明缺乏唯一核心**。没有绝对主线龙头，是当前行情最大的结构性缺失。

第三，**拐点是在美伊冲突再起的背景下完成的**。外部冲击下指数仍能下探回升、情绪同步回暖，这种"利空中走强"是新周期起点概率较大的信号。但要注意这是概率判断，不是确认——确认权交给后面两天的指数结构。

## 二、情绪与指数结构：两个关键验证点

接下来一两个交易日，盯死两件事，任何一件证伪都要降级处理：

**验证点1（指数强度底线）**：明后天出现分歧时，全A指数必须相对强势、不能破位。一旦破位，行情大概率回归到5月22日那种杀跌场景里去。也就是说，这根阳线的"拐点身份"是有有效期的，破位即失效。

**验证点2（聚焦度）**：正常的情绪上升周期都会逐步收敛出一个明显的聚焦方向。如果持续只有轮动、出不来聚焦，那就意味着——**有轮动上涨，没有高度空间**。这对趋势行情（拿住板块、看月线）没问题；但对短线打板/接力结构是不友好的，因为没有空间高标就压不出梯队。

把这两点合起来看，理想剧本是：明天延续普涨 → 下周一开始分化 → 主线逐步明确，且**大概率从科技内部裂变出一个分支**。需要观察的是：是否有分支能主动站出来引领大盘情绪，把这一轮上涨的情绪结构补完整。

## 三、主线全景：AI科技产业链的轮动地图

今天的核心矛盾是"产业链多点开花但无核心"。按重要性和因果先后排一下：

**1）光通信/CPO —— 真正的盘面核心** 上午科技多方进攻没能共振，直到下午CPO发力才把指数带起来。光通信仍是科技里最硬的核心，"易中天"三巨头（新易盛、中际旭创、天孚通信）齐创历史新高，安孚科技反包涨停。这是今天唯一能称得上"带动指数"的方向，但它已经是高位品种，更多是确认产业景气、而非提供新的情绪空间。

**2）上游涨价链 —— 当日表现最突出、扩散最广** 这是今天真正有"新意"的方向，也最符合国内公司在AI产业链中的定位（上游材料+中下游配套相对更有竞争力）。

- 已发动：电容/MLCC、培育钻石(金刚石)领涨；CCL/电子布、磷化铟、薄膜铌酸锂同步走强。
    
- 涨价逻辑的扩散路径值得跟踪：模拟芯片走强 → 下一步大概率轮到**功率半导体、高频变压器**补涨 → **SST（固态变压器）**的炒作有望提上日程。
    
- 这条链的好处是"涨价"叙事自带基本面锚，能容纳更多资金；缺点是分散，难出单一高标。
    

**3）半导体制造** 晶圆代工、硅片领涨，华虹公司大涨超15%续创新高（且是今日机构净买入第一，6.26亿）。先进封装因为前期涨幅较大调整了一天，明天大概率重回强势。这里要重点关注**芯碁微装**（机构净买入4.88亿）——PCB直写光刻DI设备全球龙头，同时卡位先进封装（WLP2000 for Bumping已出货、类CoWoS-L已助力头部客户量产、2026下半年量产爬坡）、IC载板、掩模版多个高景气环节，是"涨价链+国产替代+先进封装"三重逻辑的交集。

**4）PCB链** 宝鼎科技9天6板创新高，宏和科技5天3板，是当前连板高度的载体。**华塑控股**作为PCB微型钻针的间接"铲子股"（子公司宏创智能全自动微钻磨削设备），被定位为三个高标里最好的投机载体——但要清醒：它和基本面关系不大，主要是情绪炒作和连板空间被压制后的突破诉求。这类标的只能用情绪仓位、严格按板理打。

**5）电力 —— 唯一的非科技投机载体** 华电能源4连板、粤电力A二连板、惠天热电/甘肃能源涨停。电力的炒作噱头本质也是"AI需要能源支撑"，所以它其实是科技叙事的外延，而非独立主线。

下跌方向：白酒集体调整（金种子酒、金徽酒、皇台酒业下挫），消费昨天短暂过渡后今天再度走弱。资金的"喜新厌旧"非常明确，防御和消费暂时不是战场。

## 四、新催化：CPU自研主题（今日最值得深挖的增量）

今天最重要的"新变量"是**字节跳动被曝正在自研定制CPU**（路透独家）。这条新闻的产业意义和A股映射链条要拆清楚：

**因果链（产业侧）**： AI开发重心从训练全面切到推理 → 推理对CPU的依赖与消耗量级跃升 → 叠加CPU长期供应短缺、价格飙升（字节从Intel/AMD采购，季度环比涨10–35%；Intel警告服务器CPU交期长达6个月；AMD苏姿丰警告全球供应紧张）→ 大厂被迫自研以对冲成本和供应（字节在Arm与RISC-V两种架构间权衡，且已与多家外部伙伴接洽设计与代工）。 这不是孤例：谷歌、亚马逊、微软都在做定制CPU；国内百度（昆仑芯）、阿里（倚天710）、腾讯（紫霄）也在持续推进自研服务器CPU的集群化。**全球高端CPU现货库存早在2026 Q1已被订空，AMD交期拉长至20周以上**——这给国内CPU配套产业链打开了确定性的增量窗口。

**A股映射（两条最干净的卡位）**：

- **ST得润（CPU Socket）**：CPU出货量与Socket是1:1刚性绑定，每一颗自研或外采CPU都必须配一个Socket才能上板。得润是中国大陆唯一通过Intel官方认证、并量产千针级CPU Socket（覆盖LGA1700/1851/1954）的上市公司，全球仅四家；鹤山二期已量产、产能就绪。当前鸿腾精密+嘉泽占全球Socket份额90%且产能饱和，外溢订单优先流向认证体系内的稀缺替代产能。风险点（ST身份）需要明确：公司公告未触及强制退市三条红线，3月27日证监会已结案，一季报核心主业造血修复——这对ST状态下资金极紧张的公司是关键变量。但ST标的的流动性与监管约束不能忽视，仓位与风控要单独对待。
    
- **万通发展 / 数渡科技（PCIe Switch）**：这是"超节点GPU互联"赛道里A股稀缺的体系化进口替代核心标的。逻辑是：CPU翻倍预期 + 国产超节点放量 → PCIe Switch市场大幅扩容（2026年国内超200亿，指数级增速）。数渡是国内极少数掌握PCIe 5.0交换芯片全流程自主设计并量产的企业，可原位替代博通：104通道已量产、144通道已投片（2026年内销售）、PCIe 6.0/CXL在研。弹性测算：一颗CPU对应2颗PCIe 5.0 Switch（2×600=1200美金）。五项专利壁垒（CXL报文调度、路由+功耗、虚通道共享缓存、硬件RDMA、二维脉动阵列调度）构成闭环。股权激励目标：26年144通道量产收入≥6亿、27年PCIe 6.0收入≥12亿。
    

CPU主题的价值在于：它可能就是后面"从科技裂变出来的那个分支"的候选之一——有明确的产业催化（字节新闻）、清晰的1:1配套逻辑、以及国产替代的稀缺标的。值得作为接下来聚焦度验证的重点观察对象。

## 五、散热与SST：景气延伸的两条支线

**液冷（散热迭代刚需）**：

- **飞荣达**：华为散热战略供应商，是微泵液冷+风扇方案最核心标的。催化来自华为何庭波发布"韬(τ)定律"、秋季麒麟芯片采用逻辑折叠技术——晶体管密度提升必然带来更严峻散热问题，华为前瞻布局微泵液冷+风扇替代传统VC和石墨（Mate80 Pro Max风驰版首搭微型风扇，Mate90有望标配）。卖方测算明年业绩对应当前估值不到20x PE，第一步看400亿、约60%空间。
    
- **液冷cage三标的（鼎通科技、奕东电子、意华股份）**：行业节奏是关键。鼎通去年Q4开始出货液冷cage样品，奕东滞后约半年——当下正是奕东股价变化的关键时间点（海外大厂来审厂、海外连接器大客户月内送样、6月有望部分出货，数十万套产能已建成）。大规模放量在27/28年，市场空间从此前10–20亿迅速扩到约300亿。海外方向主要是鼎通+奕东给安费诺/立讯代工；国产华为侧此前空缺，现在意华切入刚放量（利润低于海外但蛋糕大）。卖方目标：鼎通700亿、奕东500亿。注意奕东股价低于鼎通1/2，存在预期差修复空间，但这些都是卖方测算，需自行折价。
    

注意：**奕东电子在今日文档的"焦点公司"里被单独拎出来**（液冷+铜缆高速连接+安费诺+数据中心），且公司同时具备连接器、光模块外壳、FPC、背光多业务——它实际上是"液冷cage + 高速连接 + 光模块配套"的多重交集，是这一轮散热+连接逻辑里值得放在第一梯队跟踪的标的。

**SST（固态变压器）—— 上游涨价链的下一站**：

- **白云电器**：与国内少数已实现SST商业化的为光能源深度合作，推出效率98.5%、成本降50%以上、获官方鉴定的SST方案，已在自有园区光储直柔项目稳定运行并落地联通大湾区数据中心，另为地铁提供750V直流配电。逻辑是AI算力集群功率飙升、传统变压器逼近物理极限，SST是必然替代。这条线和"功率半导体/高频变压器补涨"的扩散方向同源，是涨价链向中游设备延伸的代表。
    

## 六、宏观与结构性背景：两条"金融化AI"的远期叙事

今天还有两条更高维度的信息，短期不影响盘面，但定义了AI产业的金融化方向，值得记进框架：

**1）中国拟开发"AI token期货"**：上海期货交易所正处于设计所谓AI代币期货合约的早期阶段——代币是AI模型处理的最小信息单位，到2026年3月中国日均代币使用量将飙升至140万亿。这与美国CME、ICE准备推出"GPU计算期货"形成中美两条不同路径的竞争：**美国走"算力(GPU compute)金融化"，中国探索"词元(token)金融化"**。本质都是给快速增长的AI成本提供对冲工具。这是一个把"算力/token"变成可交易标的的范式信号，长期会重塑整个AI成本结构的定价方式。

**2）SemiAnalysis：AWS靠Bedrock实现利润反转**（5月28日深度）——这条最值得反复咀嚼，因为它揭示了AI变现的真实经济学：

- AWS过去八个季度增速落后于Oracle/CoreWeave/Azure，但靠**Bedrock的"代币即服务(TaaS)"模式 + 折旧政策拉长**实现了利润率反转。
    
- 关键区分：**IaaS（如五年期take-or-pay合同）收入锁定性强、风险低、但毛利率低**；**TaaS（Bedrock卖Claude）收入锁定性更低、客户用量灵活、但利润率更厚**。
    
- 测算结论：固定IaaS费用 + 收入分成 + 超量绩效门槛叠加，使Bedrock在2026 Q1实现约**55%的EBIT利润率**；Bedrock占AWS收入比从2025 Q1的约9%升至2026 Q1的约15%，毛利率约30%，已成为AWS增量利润的核心。
    
- 代价对称且明确：**若Claude的token消费下滑，AWS承担的需求风险高于传统IaaS**——这是TaaS高利润的另一面。
    
- 同时AWS的护城河是定制芯片（Trainium加速器、Graviton CPU）——这又回到了第四节"大厂自研芯片"的同一条产业逻辑：**自研芯片是云厂商压低成本、撑起利润率的底层武器**。
    

这条信息和字节自研CPU新闻是同一枚硬币的两面：**全球云厂商都在用"自研芯片 + token化变现"重构AI的成本与利润结构**。A股的CPU配套、PCIe Switch、液冷、SST，全都是这个全球资本开支与降本周期在国内的映射。

## 七、核心矛盾与认知盲点

1. **"无核心"是当前最大的脆弱点**。今天是普涨轮动，但普涨之后必须收敛出聚焦，否则只有宽度没有高度。最大盲点是误把"轮动普涨"当成"主升趋势"——前者对短线接力结构不友好，容易在分歧日被一根破位阴线打回原形。
    
2. **拐点的有效性高度依赖外部环境**。这根阳线是在美伊冲突下完成的，所以"新周期起点"是概率判断。如果外部冲突升级超预期，或全A在分歧时破位，拐点逻辑随时作废——不要把概率当确定性。
    
3. **高位品种 vs 低位涨价品种的取舍**。光通信/CPO是核心但已在高位、提供的是确认而非空间；上游涨价链（功率半导体、高频变压器、SST、电子布等）位置更低、扩散更广，可能是更好的进攻方向。盲点是：在情绪修复初期把仓位压在已经兑现的高位核心上，而非位置更优的扩散分支上。
    
4. **ST/题材股的风控不能被叙事掩盖**。ST得润逻辑再硬，也是ST身份；华塑控股逻辑再顺，本质也是情绪炒作的投机载体。卖方给的700亿/500亿/400亿目标都是测算，需自行打折。这类标的的仓位、止损纪律要独立于普通持仓。
    
5. **别忽略缩量**。2.97万亿、缩量2704亿——修复是在量能收缩中完成的。如果普涨没能换来量能跟上，聚焦和高度都缺乏燃料，这是验证点2背后的资金面注脚。

## 📖 专业术语注解（增量）

### 盘面与结构

| 术语        | 含义                                                            |
| --------- | ------------------------------------------------------------- |
| **V型修复**  | 指数先大幅下杀再快速拉回的走势形态，日内完成"跌→涨"的方向逆转，是情绪拐点的典型图表                   |
| **主升确认**  | 确认市场已进入主升浪（上涨趋势中最强劲的一段）的信号，通常需要放量突破关键阻力位                      |
| **右侧第一根** | 趋势交易术语。左侧=下跌中抄底，右侧=确认拐点后入场。"右侧第一根"指拐点确认后的首根阳线，此时仓位应偏保守，不等同于追高 |
| **普涨式轮动** | 大量板块同时上涨但无清晰领涨方向，资金在各个分支间快速轮转。轮动越全面，越说明缺乏唯一核心                 |
| **聚焦度**   | 市场资金在某一方向上的集中程度。聚焦度高=有明确主线、能出高标；聚焦度低=只有宽度没高度                  |
| **分歧日**   | 上涨后多空双方力量出现对抗的交易日，通常伴随震荡、分化，是检验上涨成色的关键窗口                      |
| **破位**    | 跌破关键支撑位（如均线、前低、成交密集区），意味着趋势结构被破坏，原判断需要降级或作废                   |
| **高度空间**  | 题材或个股能走出的上涨幅度上限。没有聚焦就没有高度空间，因为没有领涨龙头压不出接力梯队                   |

### AI产业链专用

| 术语 | 含义 |
|------|------|
| **MLCC** | 多层陶瓷电容器（Multi-Layer Ceramic Capacitor），片式电容的主流形态。AI服务器用量远超传统服务器，是涨价链核心品种 |
| **培育钻石/金刚石** | 人工合成的金刚石材料，除珠宝外，作为第四代半导体材料（超宽禁带）可用于高功率/高频器件和散热衬底，是AI产业链上游新材料 |
| **CCL** | 覆铜板（Copper Clad Laminate），PCB的核心原材料。电子布+铜箔+树脂压合而成，AI高频高速PCB需求驱动升级 |
| **电子布** | 电子级玻璃纤维布，CCL的增强材料。AI驱动的高速PCB对电子布的介电性能要求更高 |
| **磷化铟 (InP)** | III-V族化合物半导体，电子迁移率远超硅，用于光通信激光器/探测器、高频射频器件，是CPO和光模块的核心衬底材料 |
| **薄膜铌酸锂 (TFLN)** | 新一代电光调制器材料，调制速率和带宽远超传统铌酸锂和硅光方案，是下一代光通信模块的核心技术路线 |
| **CPO** | 共封装光学（Co-Packaged Optics），将光模块和交换芯片共同封装在同一基板上，极大缩短电信号传输距离，降低功耗和延迟 |
| **CPU Socket** | CPU插座，CPU与主板之间的物理+电气连接接口。每一颗CPU必须配一个Socket才能上板，1:1刚性绑定。LGA=触点阵列封装，是目前主流Socket形态 |
| **PCIe Switch** | PCIe交换芯片，用于扩展CPU的PCIe通道数，实现多GPU/多加速器互联。超节点GPU互联场景下需求翻倍，国内2026年市场超200亿 |
| **CXL** | Compute Express Link，基于PCIe物理层的高速互连协议，支持CPU-GPU-内存之间的缓存一致性和资源共享 |
| **RDMA** | 远程直接内存访问（Remote Direct Memory Access），允许数据直接从一个计算机内存传输到另一个计算机内存而无需CPU参与，是高性能计算和AI集群互联的关键技术 |
| **二维脉动阵列** | 一种并行计算硬件架构，数据在PE阵列中以"脉动"方式流动，是AI加速器（TPU等）和交换芯片中的核心调度引擎 |
| **Bumping** | 凸块工艺，在晶圆上制作微小焊料凸点，用于芯片与封装基板的电气连接。是先进封装（Flip-Chip）的基础工艺 |
| **CoWoS-L** | 台积电的一种先进封装技术变体，在CoWoS基础上引入局部硅桥（LSI）替代完整中介层，兼顾性能和成本 |
| **液冷cage** | 液冷系统中的笼式连接器组件，是液冷服务器中液体分配和接口连接的核心机械部件，数十万套级产能对应数百亿市场 |
| **微泵液冷** | 利用微型泵驱动冷却液在芯片表面循环的主动式散热技术，散热能力远超被动式VC和石墨方案，是下一代手机/PC/服务器的散热方向 |
| **VC** | 均热板（Vapor Chamber），利用液体相变传热的被动散热元件，当前手机和轻薄本的主流散热方案，正被微泵液冷替代 |

### 产业链与制造

| 术语 | 含义 |
|------|------|
| **直写光刻 (DI)** | Direct Imaging，用激光直接在PCB/基板上绘制电路图案，无需传统掩模版。芯碁微装是该领域全球龙头 |
| **IC载板** | IC Substrate，芯片与PCB之间的中介基板，精度要求远高于普通PCB，是先进封装的必需材料 |
| **掩模版** | 光刻工艺中用来将电路图案转移到晶圆/基板上的母版，芯片制造的核心耗材 |
| **铲子股** | "淘金热中卖铲子"的投资理念——不直接押注终端产品（淘金），而是投资上游必需的设备/材料/工具（铲子）。华塑控股为PCB提供微型钻针设备，属于典型的铲子股 |
| **审厂** | 客户对供应商工厂进行的资质审核和工艺验证，是进入供应链的必经门槛。奕东电子当前正处于海外大厂审厂的关键节点 |
| **送样** | 向客户提交产品样品进行测试验证，送样通过后才能进入批量供货阶段 |
| **交期** | 从下单到交货的时间周期。CPU交期拉长至6个月/20周以上，意味着供应极度紧张 |

### 宏观与商业模式

| 术语 | 含义 |
|------|------|
| **TaaS** | Token as a Service，代币即服务。AWS Bedrock的商业模式：客户按AI模型处理的token量付费，而非按固定算力租用。利润率高但需求风险也高于固定合同 |
| **IaaS** | Infrastructure as a Service，基础设施即服务。传统云服务模式，客户租用固定算力/存储资源。take-or-pay合同锁定量大，收入稳定但毛利率较低 |
| **take-or-pay** | 照付不议合同条款，客户承诺最低采购量，达不到也需支付约定金额。IaaS常用此锁定收入 |
| **EBIT利润率** | 息税前利润率，衡量主营业务盈利能力的核心指标。Bedrock 2026Q1约55%的EBIT利润率远超传统IaaS |
| **token期货** | 将AI模型的token消耗量作为标准化期货合约标的物。中国上期所正在早期设计阶段，本质是给AI成本提供对冲工具 |
| **自研芯片** | 云/互联网大厂自主设计而非采购第三方芯片，目的是降低成本、摆脱供应链依赖。谷歌/亚马逊/微软/字节/阿里/腾讯均在推进 |
| **股权激励** | 以股权形式激励管理层/核心员工完成业绩目标。数渡科技26年≥6亿/27年≥12亿的股权激励目标既反映管理层信心，也是投资的关键验证节点 |

### 操作与风控

| 术语 | 含义 |
|------|------|
| **预期差** | 市场当前定价与实际价值之间的差距。奕东股价低于鼎通1/2但业务逻辑相似，存在预期差修复空间 |
| **卖方测算** | 券商/研究机构的估值预测，通常偏乐观，需要投资者自行打折折价后参考 |
| **情绪仓位** | 仅用短期情绪博弈逻辑持有的仓位，不与基本面长期绑定。ST/题材/连板股通常只能用情绪仓位参与 |
| **板理** | "打板"的交易纪律和规则体系，包括什么板能打、什么板不能打、仓位多少、止损位在哪等 |
| **打回原形** | 短暂修复后快速跌回起涨点甚至更低。是"无核心轮动行情"最常见的失败模式，一根破位阴线即可抹去所有修复成果 |
| **降级处理** | 当前市场判断被证伪时，主动降低仓位和预期。"破位即降级"是核心风控原则 |
