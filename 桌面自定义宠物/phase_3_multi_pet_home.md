# 阶段 3：多宠物与家园版本

## 1. 阶段目标

实现多只宠物同时显示，并加入桌面家园装饰系统。

本阶段是产品从“桌面宠物工具”升级为“桌面宠物生活空间”的关键版本。

## 2. 玩家体验目标

玩家可以把多只自己的宠物放到桌面上，看它们互相靠近、一起睡觉、追逐、打闹，也可以布置一个桌面小家，让宠物回到窝里、玩玩具、吃东西或休息。

## 3. 功能需求

### 3.1 多宠物系统

- 支持创建多只宠物档案
- 支持选择当前显示哪些宠物
- 支持同时加载多只宠物
- 支持设置每只宠物大小
- 支持设置每只宠物性格
- 支持每只宠物独立位置
- 支持宠物头顶名字显示开关
- 支持宠物分组

分组示例：

- 猫猫组
- 狗狗组
- 我的家
- 办公陪伴组

### 3.2 多宠物互动

互动行为建议：

- 互相靠近
- 一起睡觉
- 追逐
- 打闹
- 互相观察
- 争抢玩具
- 跟随领头宠物
- 一起响应玩家打字
- 一只宠物被点击时，其他宠物围观

行为规则：

- 同屏宠物数量越多，单只宠物随机行为频率适当降低
- 宠物之间需要避免重叠过多
- 宠物互动需要有冷却时间
- 多宠物互动优先级高于普通待机行为，但低于玩家直接交互

### 3.3 桌面家园

桌面家园是一个可以放在桌面上的宠物生活区域。

基础功能：

- 放置宠物窝
- 放置食盆
- 放置玩具
- 放置地毯
- 放置植物或小装饰
- 家园区域可以拖动
- 家园区域可以缩放
- 宠物可以回到家园区域
- 宠物可以使用家园里的家具

### 3.4 家园编辑模式

编辑功能：

- 打开和关闭编辑模式
- 添加家具
- 移动家具
- 删除家具
- 调整家具层级
- 旋转家具，可选
- 保存家园布局
- 重置家园布局

### 3.5 家具互动

家具需要配置互动点。

家具示例：

- 宠物窝：睡觉
- 食盆：吃饭
- 玩具球：追逐或拍打
- 地毯：趴下
- 小架子：跳上去或靠近
- 纸箱：躲进去

程序需要为家具配置：

- 家具 ID
- 家具类型
- 显示资源
- 碰撞区域
- 互动点位置
- 可触发行为
- 层级规则

程序交付内容：

美术交付内容：

## 6. 验收标准

本阶段完成标准：

- 玩家可以同时显示多只宠物
- 多只宠物可以各自待机、移动、睡觉和响应玩家操作
- 多只宠物之间可以触发至少 3 种互动
- 玩家可以放置一个桌面家园区域
- 玩家可以添加、移动、删除家具
- 宠物可以和至少 3 种家具产生互动
- 家园布局和多宠物显示状态可以保存并恢复
- 同屏多只宠物时性能稳定

## 7. 阶段风险

主要风险：

- 多宠物同时活动容易造成桌面混乱
- 多实例动画和输入响应可能增加性能压力
- 家园编辑器开发量较大
- 家具层级和宠物遮挡关系容易出错
- 多宠物互动如果过少，会显得只是多个单宠物叠加
