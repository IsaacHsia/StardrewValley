# 桌面宠物工具项目总览

## 1. 项目定位

项目暂定名：桌面宠物工坊

项目类型：Steam 桌面互动工具 / 轻度陪伴 / 桌面装饰 / 宠物养成

核心体验：

玩家上传自己宠物的照片，将真实宠物生成可在 Windows 桌面活动的桌面宠物。宠物会根据玩家打字、鼠标操作、空闲状态等行为做出随机反应，让玩家在办公、学习或休闲时感受到宠物陪伴。

目标用户：

- 喜欢猫、狗等宠物的用户
- 需要办公陪伴感的桌面用户
- 喜欢 Steam 小工具和桌面美化软件的玩家
- 喜欢轻度养成、装饰和收集的用户

核心卖点：

- 用自己的真实宠物照片生成桌面宠物
- 宠物会响应键盘、鼠标和空闲状态
- 支持多只宠物同时出现在桌面
- 支持桌面家园装饰
- 可拍照、截图、分享自己的宠物桌面

## 3. 总体技术模块

程序模块建议：

- 桌面窗口模块：透明窗口、置顶、鼠标穿透、多显示器、窗口拖拽
- 宠物数据模块：宠物档案、照片路径、名字、性格、显示状态、存档
- 图片处理模块：图片导入、压缩、抠图、透明背景处理、素材缓存
- 渲染动画模块：宠物精灵、动画播放、缩放、翻转、层级排序
- 行为 AI 模块：状态机、随机行为、输入响应、宠物情绪、多宠物互动
- 输入监听模块：键盘频率、鼠标位置、鼠标速度、空闲时间检测
- 家园模块：家具摆放、装饰保存、宠物互动点、主题切换
- UI 设置模块：宠物管理、设置面板、家园编辑、照片导入流程
- Steam 模块：Steam SDK、云存档、成就、创意工坊、商店构建

## 4. 总体美术资源方向

MVP 必需资源：

- 默认猫宠物一只
- 默认狗宠物一只，可选
- 基础动作：待机、走路、睡觉、看鼠标、被点击、被拖拽
- UI 图标：导入、删除、设置、显示、隐藏、置顶、鼠标穿透、宠物档案
- 主界面 UI
- 设置界面 UI
- 宠物导入引导图
- Steam 商店素材

进阶资源：

- 家具套装
- 玩具道具
- 情绪特效
- 宠物家园主题
- 多宠物互动动画
- 拍照贴纸和边框
- 节日装饰

## 5. 隐私原则

项目必须明确向玩家说明：

- 软件不记录玩家具体键盘输入内容
- 只检测键盘输入频率、鼠标位置、鼠标速度、空闲状态
- 宠物照片默认保存在本地
- 若后续加入云端 AI 处理，必须单独授权，并说明上传内容、用途和删除方式

## 6. 推荐首发策略

首个 Steam 版本建议聚焦在一只宠物的真实陪伴感：

- 上传宠物照片
- 生成透明背景桌面宠物
- 宠物可待机、走动、睡觉、响应鼠标和键盘
- 玩家可以调整大小、位置、置顶和鼠标穿透
- 所有数据本地保存

多宠物、家园、创意工坊和高级 AI 动画建议作为后续大版本更新，降低首发技术风险。
