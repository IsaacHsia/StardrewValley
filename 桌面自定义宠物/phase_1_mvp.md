# 阶段 1：MVP 可上架版本

## 1. 阶段目标

做出可以在 Steam 上售卖的最小完整产品。

本阶段重点不是做复杂 AI 生成或大型家园系统，而是把“上传自己的宠物照片，让宠物在桌面陪伴自己”这个核心卖点做完整、稳定、可理解。

## 2. 玩家体验目标

玩家可以上传自己的宠物照片，创建一个宠物档案，并在桌面上生成一只可互动的桌面宠物。宠物会待机、走动、睡觉，并根据鼠标和键盘操作做出简单反应。

## 3. 功能需求

### 3.1 宠物导入

- 支持导入 JPG、PNG、WEBP
- 支持一次上传多张照片
- 支持选择一张照片作为主形象
- 支持宠物命名
- 支持选择宠物类型：猫、狗、兔子、其他
- 支持创建、删除、重命名宠物档案
- 支持重新导入照片
- 支持照片质量提示

推荐照片提示：

- 正面清晰
- 背景尽量干净
- 宠物主体完整
- 光线稳定
- 不要过度遮挡宠物身体

### 3.2 宠物生成

MVP 建议采用“照片抠图 + 轻度动画模板”的方式。

功能要求：

- 玩家选择主图
- 系统生成透明背景宠物素材
- 若自动抠图失败，允许玩家重新选择图片
- 宠物以 2D 精灵形式显示在桌面
- 支持缩放、翻转、轻微旋转、弹跳等轻动画

### 3.3 桌面互动

基础行为：

- 玩家打字时，宠物看向键盘方向或做围观动作
- 玩家快速打字时，宠物进入兴奋或好奇状态
- 鼠标靠近宠物时，宠物抬头或看向鼠标
- 鼠标悬停宠物时，宠物做亲近动作
- 玩家点击宠物时，宠物做撒娇、惊讶或躲开动作
- 玩家拖拽宠物时，宠物进入被抱起状态
- 玩家长时间无操作时，宠物睡觉
- 宠物随机在屏幕边缘走动、趴下或待机

### 3.4 设置系统

玩家可配置：

- 宠物大小
- 宠物显示或隐藏
- 是否置顶
- 是否鼠标穿透
- 行为频率
- 音效开关
- 开机自启动
- 当前显示器
- 隐私设置说明

### 3.5 本地存档

需要保存：

- 宠物档案
- 宠物照片路径
- 生成后的素材缓存路径
- 宠物名称
- 宠物类型
- 宠物大小
- 宠物桌面位置
- 软件设置

## 4. 程序需求

程序交付内容：

- 宠物导入系统
- 图片格式检测与压缩
- 基础抠图或透明背景处理流程
- 宠物档案管理
- 桌面宠物渲染
- 行为状态机
- 输入监听模块
- 设置面板
- 本地存档
- 开机自启动
- Steam SDK 基础接入
- 崩溃日志和错误提示

建议模块：

- PetProfileManager
- PetPhotoImporter
- PetSpriteGenerator
- DesktopPetRuntime
- PetBehaviorStateMachine
- UserActivityWatcher
- AppSettingsManager
- SaveDataManager
- SteamIntegration

## 5. 美术需求

美术交付内容：

- 主界面 UI
- 设置界面 UI
- 宠物导入流程 UI
- 宠物档案卡片
- 照片质量提示图
- 默认猫宠物素材
- 默认狗宠物素材，可选
- 通用动画模板
- 行为状态图标
- 抠图成功、失败反馈视觉
- Steam 商店胶囊图
- Steam 商店截图
- 宣传图

MVP 动作建议：

- 待机
- 走路
- 睡觉
- 看鼠标
- 被点击
- 被拖拽
- 打字围观

## 6. 隐私需求

必须在设置或首次启动中明确说明：

- 软件不会记录具体输入内容
- 键盘检测只用于判断输入频率
- 照片默认保存在本地
- 用户可以删除本地宠物数据
- 若后续接入云端 AI，需要另行授权

## 7. 验收标准

本阶段完成标准：

- 玩家可以导入宠物照片并创建宠物档案
- 玩家可以让一只自己的宠物显示在桌面上
- 宠物可以响应鼠标靠近、点击、拖拽和键盘输入
- 宠物可以自动待机、走动、睡觉
- 玩家可以调整宠物大小、位置、置顶和鼠标穿透
- 软件重启后能恢复宠物和设置
- 有完整隐私说明
- 可以打包为 Steam 可测试版本

## 8. 阶段风险

主要风险：

- 自动抠图质量不稳定
- 玩家上传照片差异过大
- 桌面透明窗口与不同系统兼容性
- 键盘监听隐私敏感
- 宠物动作过少会导致新鲜感不足
- Steam 审核时需要清晰说明软件行为和隐私策略
