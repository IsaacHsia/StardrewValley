# 阶段 2：体验增强版本

## 1. 阶段目标

让产品从“有趣工具”变成“玩家愿意长期打开的陪伴软件”。

本阶段重点是提高宠物的生命感、随机性、陪伴感和可持续使用价值。

## 2. 玩家体验目标

玩家每天打开电脑时，宠物不仅只是站在桌面上，而是会表现出性格、情绪、习惯和随机行为。玩家会期待看到宠物今天做什么，并愿意截图分享。

## 3. 功能需求

### 3.1 多照片动作素材

- 支持为同一只宠物导入多张照片
- 支持将照片分类为不同动作素材
- 支持主图、坐姿、趴姿、侧面、睡觉等标签
- 支持重新选择某个动作对应的照片
- 支持动作预览

建议照片标签：

- 正面
- 侧面
- 坐姿
- 趴姿
- 睡觉
- 表情
- 全身

### 3.2 性格系统

为宠物增加性格，影响行为权重。

性格建议：

- 黏人：更容易靠近鼠标，更常响应玩家操作
- 懒散：更常睡觉和趴着
- 活泼：更常走动、跳跃和随机互动
- 胆小：鼠标靠近时可能躲开
- 好奇：更常观察鼠标和键盘

功能要求：

- 玩家可选择性格
- 支持自动推荐性格，可选
- 性格影响行为概率
- UI 中显示性格标签

### 3.3 情绪系统

增加宠物当前情绪。

情绪建议：

- 平静
- 开心
- 困
- 好奇
- 兴奋
- 委屈

情绪影响：

- 动作选择
- 头顶气泡
- 音效
- 随机事件
- 和玩家互动的反馈

### 3.4 每日陪伴事件

轻量事件建议：

- 第一次启动时宠物打招呼
- 长时间办公后宠物提醒休息
- 晚上宠物更容易睡觉
- 连续打字时宠物围观
- 长时间无操作时宠物趴在桌面边缘
- 每天随机出现一次特殊动作

### 3.5 拍照分享

功能需求：

- 截取当前宠物画面
- 支持隐藏 UI 拍照
- 支持添加简单贴纸或边框
- 支持保存本地图片
- 支持快速打开截图目录

### 3.6 高级设置

新增设置：

- 透明度
- 行为频率
- 随机走动范围
- 是否响应键盘
- 是否响应鼠标
- 是否显示宠物名字
- 是否启用休息提醒
- 当前显示器选择
- 性能模式

## 4. 程序需求

程序交付内容：

- 多照片素材管理
- 照片动作标签系统
- 行为权重系统
- 性格数据系统
- 情绪数据系统
- 每日事件调度
- 截图与拍照系统
- 高级设置系统
- 更稳定的多显示器支持
- 性能模式

建议模块：

- PetAssetLibrary
- PetPoseTagger
- PetPersonalitySystem
- PetMoodSystem
- DailyEventScheduler
- PetSnapshotService
- AdvancedSettingsPanel
- PerformanceProfileManager

## 5. 美术需求

美术交付内容：

- 多动作模板
- 性格标签图标
- 情绪图标
- 头顶气泡效果
- 轻量粒子效果
- 拍照模式 UI
- 拍照边框
- 贴纸
- 更多默认宠物动作
- 设置面板扩展 UI

动作扩展建议：

- 伸懒腰
- 打滚
- 清洁身体
- 趴键盘旁边
- 偷看鼠标
- 惊讶
- 开心跳动
- 困倦打哈欠

## 6. 验收标准

本阶段完成标准：

- 同一只宠物可以配置多张动作照片
- 宠物性格会明显影响行为表现
- 宠物有基础情绪变化
- 宠物会触发每日随机事件
- 玩家可以拍摄并保存宠物截图
- 高级设置可以调整陪伴强度和性能
- 多显示器表现稳定

## 7. 阶段风险

主要风险：

- 行为过于随机会显得没有规律
- 情绪系统如果反馈不足，玩家感知弱
- 多照片管理会增加 UI 复杂度
- 截图分享涉及桌面隐私，需要避免误截玩家敏感内容
- 过多动画可能增加性能压力
