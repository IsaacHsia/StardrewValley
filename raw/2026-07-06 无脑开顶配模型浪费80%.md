# 无脑开顶配模型 ≈ 给每颗螺丝配航空发动机

"越贵越聪明"是 AI 使用中最昂贵的错觉。一个特效图改名没同步的问题，丢全量项目日志 + 开最贵模型 + max thinking + fast 模式，花了 2000+ token 定位；同事一看 5 秒就找到——问题不是 AI 不够强，是你没给它正确的范围。

**与我的关联：** 如果你习惯遇事不决直接上 Sonnet/Opus + 全量上下文，你 80% 的 token 都花在"让 AI 帮你筛垃圾"上。

**值得深挖吗：** 是。模式选择（Ask/Plan/Agent）+ 模型分级的 ROI 远大于无脑堆算力。

> [!tip]- 详情
> **案例：**
> - 包体构建失败 → 把整个项目说明 + 所有日志 + 两周提交记录全丢给 AI
> - 开最贵模型 + highest thinking + fast 模式，一个操作花掉 2000+ token
> - AI 看了半天说"可能是资源路径问题"
> - 同事一看：特效图改名没同步，5 秒定位
>
> **暴力流派的三个问题：**
> 1. 贵模型在简单问题上不会比中等模型好百倍，但贵百倍
> 2. 大部分 token 花在"定位和筛垃圾"而非解决问题上
> 3. Agent 模式 + subagent 更是 token 消耗的核弹
>
> **正确做法：**
> - **先问准**："构建失败，下面是核心报错和最近改动" — 不需要全量
> - **模式选对**：只是问问题用 Ask，复杂任务先 Plan 再 Agent
> - **Agent 前确认**：验收标准是什么？它申请了什么权限？subagent 要不要开？
> - **模型分级**：翻译/润色/改路径 → 便宜快速模型；长链路推理 → 中高阶；多文件重构 → 强模型
>
> **核心：** AI 不是越猛越好，是越合适越好。给它正确范围 + 正确模式，中等模型也够用。
