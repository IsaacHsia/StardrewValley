
# 认识Log与Lut
Log灰片：保留更多画面细节
将灰片还原：LUT(Look Up Table)——通过查找画面每一个像素的颜色，替换成预设好的另一个颜色
![[截屏2026-07-07 13.23.49.png]]
导入LUT预设文件。
不同的Log曲线灰片对应不同的LUT预设
可以直接编辑片段，添加LUT效果，也可以直接左上角拖拽LUT下来变成一个轨道

# 基础调色
- 亮度：明暗
- 饱和度：浓淡
- 色相：偏红/蓝/绿
	颜色种类，使用HSL调节

# 进阶色轮
左上角素材面板中，使用调节工具，拖动到新轨道，放在素材上方![[截屏2026-07-07 13.32.52.png]]
1. 阴影
2. 中间调
3. 高光
4. 偏移
只调整某一个区域
拖动锚点：染上对应的颜色，控制色相和一定的饱和度
左侧滑轨：同时调整色相和饱和度，滑轨越高，颜色越浓
右侧滑块：亮度

## 波形图
显示画面区域中的亮度，越高的地方越亮
## 分量图
显示颜色分布，越偏的颜色位置越高，再用色轮调整，波动偏移色轮的锚点远离蓝色

# 矢量图
![[截屏2026-07-07 13.40.57.png]]
圆心到边缘的距离，就是饱和度的高低，星星飞出去的方向，就是偏色的方向。
简单技巧：色轮里面把偏移的锚点按照星星扩散的相对方向调整
