# 5.28 A股收盘分析 — V型修复与聚焦度博弈

## 📊 盘面定性

三大指数探底回升收红，创业板指从跌超1%到涨近2%，典型的"先杀后拉"V型修复。沪深成交2.97万亿、缩量2704亿，超3000只上涨、超百股涨停。

**三层定性**：
1. 情绪拐点而非主升确认 — 按"右侧第一根"处理
2. 普涨式轮动而非主线引领 — 缺唯一核心是最大结构性缺失
3. 利空中走强 — 美伊冲突背景下指数下探回升，新周期概率提升

## 🔑 两个关键验证点

| 验证点 | 标准 | 证伪后果 |
|--------|------|----------|
| 指数强度底线 | 分歧日全A不能破位 | 回归5.22杀跌剧本 |
| 聚焦度 | 必须从轮动收敛出聚焦 | 有宽度没高度 |

剧本：明天普涨 → 下周一分化 → 主线从科技内部裂变

## 🗺 主线全景

### 光通信/CPO（盘面核心）
"易中天"三巨头（新易盛、中际旭创、天孚通信）齐创新高。唯一能带动指数的方向，但高位品种提供确认不提供空间。

### 上游涨价链（最有新意）
- 已发动：电容/MLCC、培育钻石、CCL/电子布、磷化铟、薄膜铌酸锂
- 扩散路径：模拟芯片→功率半导体→高频变压器→SST

### 半导体制造
- 华虹公司大涨15%，机构净买入第一（6.26亿）
- 芯碁微装（机构净买入4.88亿）：PCB直写光刻DI龙头 + 先进封装 + IC载板

### PCB链
- 宝鼎科技9天6板、宏和科技5天3板、华塑控股（铲子股）

## ⭐ 新催化：CPU自研主题

字节跳动自研定制CPU（路透独家）。产业逻辑：推理时代CPU消耗跃升 + 供应紧张/价格飙升 + 库存Q1已订空 → 大厂被迫自研。

| 标的 | 卡位 | 核心逻辑 |
|------|------|----------|
| ST得润 | CPU Socket | 大陆唯一Intel认证，1:1刚性绑定，全球仅四家。风险：ST身份 |
| 万通发展/数渡科技 | PCIe Switch | PCIe 5.0自主量产，可替代博通。股权激励：26年≥6亿、27年≥12亿 |

## 🧊 散热与SST

- 飞荣达：华为微泵液冷+风扇，卖方看400亿
- 液冷cage三标的：鼎通科技、奕东电子（关键时间窗）、意华股份
- 白云电器：SST商业化，效率98.5%

## 🌐 宏观远期

1. 中国拟开发AI token期货（上期所早期阶段）
2. AWS靠Bedrock实现利润反转 — TaaS模式EBIT利润率约55%

## ⚠️ 核心矛盾

| # | 矛盾 | 盲点 |
|---|------|------|
| 1 | 无核心=脆弱 | 误把轮动当主升 |
| 2 | 拐点依赖外部环境 | 把概率当确定性 |
| 3 | 高位CPO vs 低位涨价 | 压在高位兑现品种 |
| 4 | ST/题材风控 | 被叙事掩盖纪律 |

## 📖 专业术语注解（增量）

> 前日已收录的基础术语见 [[A股/开盘收盘分析/5.27收盘]] 术语集。

### 盘面与结构

| 术语 | 含义 |
|------|------|
| V型修复 | 指数先大幅下杀再快速拉回的走势，日内完成方向逆转 |
| 主升确认 | 确认市场已进入主升浪，通常需放量突破关键阻力位 |
| 右侧第一根 | 趋势交易术语，拐点确认后的首根阳线，仓位应偏保守 |
| 普涨式轮动 | 大量板块同涨但无领涨方向，轮动越全面越缺核心 |
| 聚焦度 | 资金在某方向的集中程度。高=有主线能出高标；低=有宽度没高度 |
| 分歧日 | 上涨后多空对抗的交易日，检验上涨成色的关键窗口 |
| 破位 | 跌破关键支撑位，趋势结构被破坏，原判断需降级 |
| 高度空间 | 题材能走出的上涨幅度上限，缺聚焦就缺高度 |

### AI产业链专用

| 术语 | 含义 |
|------|------|
| MLCC | 多层陶瓷电容器，AI服务器用量远超传统服务器 |
| 培育钻石/金刚石 | 第四代半导体材料，用于高功率/高频器件和散热衬底 |
| CCL | 覆铜板，PCB核心原材料，AI高频高速驱动升级 |
| 电子布 | 电子级玻璃纤维布，CCL增强材料 |
| 磷化铟 (InP) | III-V族化合物半导体，光通信激光器/探测器核心材料 |
| 薄膜铌酸锂 (TFLN) | 新一代电光调制器材料，下一代光通信核心技术 |
| CPO | 共封装光学，光模块与交换芯片共封装 |
| CPU Socket | CPU插座，与CPU 1:1刚性绑定，LGA为当前主流 |
| PCIe Switch | PCIe交换芯片，超节点GPU互联场景需求翻倍 |
| CXL | Compute Express Link，高速互连协议 |
| RDMA | 远程直接内存访问，AI集群互联关键技术 |
| 二维脉动阵列 | 并行计算硬件架构，AI加速器核心调度引擎 |
| Bumping | 凸块工艺，先进封装基础工艺 |
| CoWoS-L | 台积电先进封装变体，引入局部硅桥 |
| 液冷cage | 液冷笼式连接器组件，数百亿市场 |
| 微泵液冷 | 主动式散热技术，替代被动VC和石墨 |
| VC | 均热板，被动散热元件，正被微泵液冷替代 |

### 产业链与制造

| 术语 | 含义 |
|------|------|
| 直写光刻 (DI) | 用激光直接在PCB上绘制电路，芯碁微装全球龙头 |
| IC载板 | 芯片与PCB间的中介基板，先进封装必需 |
| 掩模版 | 光刻工艺母版，芯片制造核心耗材 |
| 铲子股 | 卖铲子思维：投资上游必需设备/材料而非终端产品 |
| 审厂 | 客户对供应商的资质审核，进入供应链必经门槛 |
| 送样 | 向客户提交样品测试，通过后才能批量供货 |
| 交期 | 下单到交货的周期，CPU交期拉长意味着供应紧张 |

### 宏观与商业模式

| 术语 | 含义 |
|------|------|
| TaaS | Token as a Service，按token量付费的AI服务模式 |
| IaaS | 基础设施即服务，固定算力租用，收入稳定但毛利率低 |
| take-or-pay | 照付不议条款，客户承诺最低采购量 |
| EBIT利润率 | 息税前利润率，Bedrock约55%远超传统IaaS |
| token期货 | 将token消耗量作为期货标的，给AI成本提供对冲工具 |
| 自研芯片 | 大厂自主设计芯片以降本脱敏供应链 |
| 股权激励 | 以股权激励完成业绩目标，数渡科技26年≥6亿/27年≥12亿 |

### 操作与风控

| 术语 | 含义 |
|------|------|
| 预期差 | 市场定价与实际价值的差距，奕东/鼎通存在 |
| 卖方测算 | 券商估值预测，需自行打折参考 |
| 情绪仓位 | 仅用短线情绪逻辑持仓，不与基本面长期绑定 |
| 板理 | "打板"的交易纪律体系 |
| 打回原形 | 短暂修复后快速跌回起涨点，无核心行情最常见失败模式 |
| 降级处理 | 判断被证伪时主动降仓位和预期，"破位即降级" |
