# 用个人积分批量生图 = 把钱扔进碎纸机

大多数人觉得"装一堆 Skills → 多开窗口并行 → 早上收菜"是高效，其实是把一个月预算烧在一周，而且大部分 token 喂给了陪跑 skills。

**与我的关联：** 如果你在用 Cursor/Claude Code 时也习惯无脑下载各种 skills 然后并行跑任务，你的 token 消耗至少有 50% 是浪费的。

**值得深挖吗：** 否。核心结论很硬——用 API 代替个人积分生图成本降 70%+，只看这一点就够了。

> [!tip]- 详情
> **问题：**
> - 用户每天下班前把十几条 prompt 分发给十几个 Cursor 任务窗口，一周烧完一个月预算
> - 没有配置 API key，直接用 Cursor 个人积分
> - 下载了大量 skills，每次指令触发一堆陪跑 skills，花了积分没给输出
>
> **解法：**
> - 批量生图/定时任务 → 用 API 替代个人积分
> - 同参数下：个人积分 4.6 模型平均一张 13.7 积分；Team AI API 平均一张 3.73 积分（成本 1/4）
> - 前期探索用低分辨率，确定方向再上高质量参数
> - 不懂 API？把调用示例丢给 AI 帮你写代码
>
> **本质：** 把个人积分消耗转为公共/团队计费，API 按实际用量付费，不浪费在陪跑基础设施上。
