# Cache 不是玄学，不懂 Cache 的 token 预算就永远算不明白

同样模型同样 token 量，账单能差一半——区别只在于对话是否命中了 cache。大多数人根本没有 cache 意识，而 cache 失效的元凶恰恰是你以为的"小操作"：中途上厕所、换模型、改 rule 措辞。

**与我的关联：** 如果你经常在长对话中切模型、改 system prompt、或者问题问一半去干别的事再回来，你的 token 浪费量至少翻倍。

**值得深挖吗：** 是。Cache 是 AI 成本优化的最高杠杆，理解透它等于白捡 50% 预算。

> [!tip]- 详情
> **Cache 机制：**
> - 相同内容短时间内重复遇到 → 平台复用之前计算结果，收费为正常 1/10
> - 但 cache 有窗口期（多数平台 5 分钟）
> - 写入条件：内容 ≥ 1024 Token，写入价格贵 1.25 倍，但多次命中很快回本
>
> **失效三件套（多数人全中）：**
> 1. **中途离开或频繁打断** — 聊天记录在，cache 不在（5 分钟过期）
> 2. **对话中换模型** — 几百 K 上下文重新给新模型算一遍，写 cache 比正常还贵
> 3. **改 Rules/系统提示词措辞** — 哪怕只是"资深"改成"顶级"，cache 就没了
>
> **最大化命中：**
> - 稳定前传放前面（项目背景、代码规则），本次问题放后面
> - 相同背景的关联问题集中连续问
> - Rules 定好就别改措辞
> - 不相关的问题直接新开窗口
