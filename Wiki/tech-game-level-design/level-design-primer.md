# 关卡策划入门 — 行业路径、作品集与设计方法论

> **核心论点：关卡策划的核心能力不是「会做地图」，而是「能用设计意图驱动玩家行为」——行业选择决定成长路径，作品集证明设计思维，方法论提供可复用的创作框架。**

## 概述

这是温润祺的关卡策划培训第二课，面向刚入行或准备入行的游戏策划，涵盖三个核心议题：

1. **行业路径选择**：单机买断制 vs 商业化手游（GaaS）——两种完全不同的职业轨迹
2. **作品集构建**：关卡策划求职需要什么、面试官在看什么
3. **设计方法论**：从零开始设计一个关卡的完整思维过程（以半条命2 逃脱关为例）

---

## Part 1. 行业路径：单机 vs 商业化手游

### 本质区别

| | 商业化游戏（GaaS） | 单机买断制 |
|---|---|---|
| **运营模式** | 长期运营、用户付费、**数据驱动** | 一次性买断、内容口碑、**作者驱动** |
| **产品哲学** | 产品上限 = 起点 | 上线 = 终点 |
| **设计导向** | 方法论 + 数据导向 | 设计内容导向 |

### 职业选择对比

| 维度 | 商业化游戏 | 单机游戏 |
|------|----------|---------|
| 待遇 | 起薪较高、旱涝保收、定时分红 | 起薪较低、回报后置 |
| 现金流 | 上线回收快 | 不稳定，研发期长 |
| 岗位数量 | 极多（95%+） | 少数团队 |
| 对应届生/跨专业 | 校招通道较多 | 保守，经验要求高 |
| 成长方向 | 方法论 + 数据导向 | 设计内容导向 |
| 风险 | 缺少亮眼项目经历 → 转向单机较难 | 非头部团队风险较高、研发期待遇较差 |

> **关键判断**：作为起点，商业化手游更容易入行，但如果目标是单机游戏，需要更早开始积累针对性的作品和项目经历。

## Part 2. 关卡策划作品集

### 关卡作品（核心）

#### 1. 关卡白盒（最好可玩）
- 5-10 分钟可玩内容
- 必须包含：**空间概念、玩家动线、游戏引导、玩法展示**
- 工具不限（Unreal/Unity/Godot），重点是**设计意图的实现**

#### 2. 关卡内的简单交互逻辑（加分项）
- 触发器
- 开门机制
- 能力门控（钥匙、解谜）

#### 3. 难度曲线设计
- 结构：**教学 → 解题 → 组合**
- 展示你对「玩家学习曲线」的理解

#### 4. 怪物布局
- 体现**遭遇设计**与**战斗节奏**的意图
- 不是「放几个怪」，而是「为什么在这里放这个怪」

### 设计文档与表达

- **规范关卡设计文档**：设计目标、空间结构、动线、引导、节奏
- **关卡平面图与动线图**：标注路径、地标等关键位置
- **设计思路**：用专业方式表达设计内容

### 游戏拆解作品

- **深度关卡拆解**：图文并茂，条理清晰
- **改进设计提案**：基于拆解系统性地提出自己的改进方案

> 拆解的核心目的：**告知读者这是一款什么游戏 + 我如何理解这款游戏的设计**。避免停留在「描述现象 + 局部建议」，要上升到**系统性的设计意图归纳和方法论提炼**。

### 差异化优势包装

- 关卡叙事 / 空间美学展示
- 跨专业转行的叙事：为什么从原专业转向游戏策划

## Part 3. 关卡设计方法论：从零到一

以 **Half-Life 2 逃脱关** 为例，展示一个关卡设计的完整思维过程。

### 设计草稿六步法

#### Step 1: 目标（Why）
> 为什么设计这个关卡？

明确关卡存在的根本理由。不是「因为游戏需要一关」，而是「这一关要让玩家体验什么」。

#### Step 2: 主题（What）
> 这个关卡的主题是什么？

- 逃脱
- 暗杀
- 潜入
- 追逐
- …

主题决定了关卡的情感基调和玩法走向。

#### Step 3: 元素清单（With What）
> 能用什么来做关卡并完成目标？

Half-Life 2 逃脱关的元素：

| 类别 | 元素 |
|------|------|
| 敌人 | 联合军警察、士兵、猎头蟹、僵尸 |
| NPC | 友好NPC（拯救、一起战斗、治疗） |
| 道具 | 撬棍、十字弩、重力枪、霰弹枪、RPG |
| 场景 | 爆炸物、载具、直升机、通风管道、暗室、手电筒 |
| 机制 | 武器、门控、物理交互 |

#### Step 4: 关卡流程（How）
> 最重要的、一定要出现在关卡中的内容——按预想流程排序。

**关键原则**：关注**逻辑性**，而非空间感和视觉性布局（那些可以之后考虑）。

```
玩家四处观察所在位置（起点）
→ 意识到被困在房间
→ 发现可能的逃跑载具（通过窗户）→ 长期目标
→ 线索提示如何逃出房间 → 短期目标
→ 通过牢房门上的洞看到外面警卫
→ 撬棍打开通风管道
→ 管道通向 1-2 个出口
→ 管道里可看到外面情况
→ 从通风管道进入多个不同房间
→ 看到一个房间关着 NPC → 可救
→ 黑暗房间 → 摸索的挑战与乐趣
→ 看到丢失的装备 → 需要十字弩或重力枪获取
→ 暗室中找到阀门 → 打开仓门逃出
→ 遭遇猎头蟹/僵尸
→ 获得十字弩/重力枪
→ 找回丢失装备 → 获得手电筒能力
→ 手电筒照亮暗房 → 找到武器/打开东西
→ 使用手电筒打开大门
→ 最终战前救出 NPC
→ 外面展开大战 → NPC 共同战斗
→ 冲向载具 → 踩油门撞死最后敌人
→ 冲上坡 → 撞碎最后障碍 → 逃脱成功
```

> **注意**：长期目标（逃脱）与短期目标（打开门/找装备/救 NPC）交替推进，保持玩家的动力。

#### Step 5: 游戏性桥段（Gameplay Beats）
> 游戏风格、情景、关键时刻。

```
潜行（距离守卫很近 → 观察、安静、寻找出口）
→ 近战武器开局（无声）
→ 得到强力武器（霰弹枪）
→ 更强武器（RPG）
→ 大型战斗（前往载具的过程中）
→ 一定程度上的非线性内容
→ 需要手电筒的暗房
→ NPC 救援 + 共同战斗
→ 载具逃脱高潮
```

**节奏设计**：潜行 → 近战 → 远程弱 → 远程强 → 大战 → 载具高潮。强度逐步攀升。

#### Step 6: 问题（Problems → Solutions）
> 通过元素来找解决方案。

| 问题 | 解决方案 |
|------|---------|
| 玩家如何逃出第一个房间？ | 撬棍 + 通风管道 |
| 得到丢失装备后解锁什么？ | 冲刺、UI、手电筒 |
| 玩家此时有什么武器？ | 撬棍、重力枪、十字弩 |
| 如果自己跑了还能救 NPC 吗？ | 在结束前某个地方让他们离开 |

## 核心设计原则总结

### 1. 长期目标 + 短期目标交替
不要让玩家迷失方向感。每一步都有明确的「下一步做什么」。

### 2. 逻辑先于视觉
设计案里先关注**逻辑性**——事件的因果链、玩家能力的递进——空间感和视觉布局可以之后再考虑。

### 3. 教学 → 解题 → 组合
这是难度曲线的通用公式：
- **教学**：在安全环境中引入新机制
- **解题**：用刚学的机制解决一个明确的挑战
- **组合**：将多个已学机制叠加

这与 DS3 高墙的教学闭环（[[ds3-lothric-high-wall-1|观察→学习→实践→奖励]]）一脉相承。

### 4. 游戏性桥段的节奏弧线
潜行 → 近战 → 远程 → 爆发 → 高潮。不是线性的难度递增，而是**强度 + 类型的交替变奏**。

### 5. 拆解的深度标准
游戏拆解的核心不是「描述现象」，而是**回答两个问题**：
- 设计者为什么要这样做？
- 背后的原则是什么？
