# 黑暗之魂3 洛斯里克高墙 关卡拆解① — 高墙前期

> **核心论点：高墙是玩家的「新手保姆」——通过 POI 兴趣点系统、光影引导、教学式战斗编排、偷袭时机控制，在玩家无意识中完成游戏基础语法的教学。**

## 概述

这是 Ymagine 的黑暗之魂3 洛斯里克高墙关卡拆解系列**第一期**，覆盖从初始之塔到高墙边塔篝火的全部流程。本期重点解析 FromSoftware 如何在一个「新手关卡」中同时完成：世界观铺垫、基础机制教学、探索习惯培养、以及——最重要的——**让玩家在不自知的情况下爱上这个世界的残酷与温柔**。

第二期 [[ds3-lothric-high-wall-2|高墙深处]] 承接本期，将复杂度大幅提升。

---

## 高墙的设计目的

作为玩家接触的**第一个大型地图**，高墙承载着明确的「新手教学」使命：

| 设计目标 | 实现策略 |
|---------|---------|
| 难度调低 | 大部分一对一战斗、区块单一出入口、纵深最多三层 |
| 世界观展开 | 场景叙事（龙尸、战火痕迹）、远景字幕 |
| 引入魂系设计 | 逐渐引入单向捷径、偷袭、宝箱怪 |
| 培养探索习惯 | 隐藏支路 + 拾取物奖励循环 |
| 建立游戏底层认知 | 「危机四伏的世界」+「散布奖励的世界」 |

---

## 地图总览

### 环状动线（2D 银河城结构）

```
初始之塔 → 龙石塔 → 火龙塔 → 高墙边塔（本期终点）
    ↑                                  ↓
    └———— 返程捷径电梯 ———— 人脓屋顶 ←┘（第二期内容）
```

水平方向看，玩家动线呈现**环状**——出发后绕一大圈，打通捷径回到原点。这与 2D 银河城游戏的设计思路同源，但由于玩家注意力聚焦在战斗和探索上，很少意识到自己在绕圈，因此捷径开通时**柳暗花明之感极强**。

### 纵向结构

- 推图路线**自上而下**，逐渐前往高墙深处
- 区块之间由**单一出入口**相连（前期低复杂度）
- 同一区块最多**三层结构**
- 上下连通路径少、复杂度低——适配新手

---

## 难度曲线：起承转合

作者以表格统计了各区块的敌人数量、种类、战斗强度，指出整体流程遵循**起承转合**的节奏：

| 阶段 | 特点 | 玩家状态 |
|------|------|---------|
| **起** | 简单战斗、低密度 | 学习基本操作 |
| **承** | 难度递进、引入新敌怪 | 应用所学 |
| **转** | 火龙演出 / 洛骑强敌 / 宝箱怪 | 情绪激化、节奏变奏 |
| **合** | 捷径 / 篝火 / NPC | 平复休整 |

> 当玩家开始对当前节奏感到厌倦时，就提供捷径或新篝火，使玩家得以休整后面对更大挑战。

## 区块拆解

### 1. 初始之塔（Iudex Gundyr 后 → 第一篝火）

**POI 兴趣点系统——玩家的第一印象**：

> 「鳞次栉比的塔楼、远景和场景字幕立刻映入眼帘，同时播放音效带给玩家强烈的第一印象。」

推开初始塔大门的第一幕，设计者做了精密的视觉信息编排：

| 设计决策 | 目的 |
|---------|------|
| 墙体不延伸到下楼楼梯，只保留两个前向延伸的侧墙 | 留出**更大的观景视野** |
| 近处可见篝火 | 提供安全锚点 |
| 篝火附近的火把光源 | 指引前进方向 |
| 远处发出幽蓝光的舞娘城楼 | 建立关卡推进的**长期预期** |

这种「视觉上特异的点吸引玩家注意力，建立关卡推进预期」的设计，在塞尔达传说·旷野之息等任系游戏中被称为 **POI（Point of Interest，兴趣点）**。

**路线控制——椅子与火把的编排**：

走下楼梯后，右侧通路被**椅子挡住入口**、火把藏在柱子背后。这不是随便放的——这是**返程的路**，难度显著高于正路（背后偷袭的弓箭手 + 两个斧头哥 + 两条狗 + 人脓），不符合难度曲线。但设计者仍然开放这一侧，并在尽头用**单向门**强制驱赶——**不封死玩家自由，但用难度和单向门温和地劝退**。

---

### 2. 龙石塔（Dragon Stone Tower）

**第一场战斗的信息编排**：

进入龙石塔区域的第一幕：
- 中间 → 延伸的道路汇聚于前进地点
- 左侧 → 高亮白光的拾取物
- 右侧 → 静止画面中**唯一运动的敌怪**

画面各处分布了适当的信息，**敌人作为最重要的信息被最明显传达**。

**提灯哥——机制教学范本**：

提灯哥的机制是「唤醒周围敌怪的攻击性」。为了让玩家清楚意识到这一点，设计者做了：

1. **行为设计**：左右张望、大声呼唤、扑腾引伴、高举提灯示意
2. **时机编排**：玩家初见观察犹豫时，身旁小怪很快被引来 → 意识到「必须马上击杀」

**观察 → 学习 → 实践 → 奖励 闭环**：

```
二楼：第二只提灯哥 + 背后三个休息的敌怪（被龙遮挡视野）
├── 速杀提灯哥 → 敌怪不醒 → 奖励（逐个击破）
└── 没速杀 → 一打四 + 火焰壶哥偷袭 → 惩罚
```

> 这完成了「观察学习 → 实践 → 奖励」的完整循环。反之则是「没学会的惩罚」。

**第一次偷袭——为什么放在这里？**

上楼后是经典的「前狼假寐盖以诱敌」陷阱。偷袭出现在这里的逻辑：
- 玩家刚经历楼下的学习战斗和奖励 → **处于放松警惕的状态**
- 此时偷袭**最容易成功、最能留下深刻印象**
- 反直觉的设计 → 奠定玩家对游戏底层性质的认知 → **让玩家在接下来的流程里提高警惕、专注观察**

**龙尸铺垫**：流程中第一次出现龙（龙头尸体）——为后续火龙塔的登场和游戏背景做铺垫。

**隐藏支路**：墙角有向下跳的支路，但**刻意不做视觉处理**——玩家不容易发现，奖励细心探索。

**制高点与望远镜**：登高最适合望远，获取望远镜是自然的。虽然它「最多用来观察防火女」。

---

### 3. 塔内（龙石塔室内）

**光影反差——节奏调节**：

塔内第一印象是**昏暗**——与刚才的户外探索形成强烈反差 → 玩家更需要集中注意力观察环境 → **调节关卡节奏**。

| 手法 | 实现 |
|------|------|
| 保护色偷袭 | 持刀小怪 = 场景保护色；持灯小怪 = 故意明显 → 击杀提灯小怪的玩家再次放松警惕 → 被偷袭 |
| 拾取物引导 | 高处拾取物激发探索欲 → 玩家回到上层寻找路径 |
| 追光源（已实锤） | 楼梯口透射极其明显的亮斑 → **解包证实是刻意放置的追光源** |

> 「起初我还以为是不是恰好环境光照到这里，但是我在解包的过程中看到了这个——他们真的刻意在这里放了一个追光源。这是故意的还是不小心？**是故意的。**」

**被封死的门**——龙石塔与火龙塔之间有一道堵死的门，既不是单向门也不是墙壁。作者推断三种可能：

1. **空间连通感**：暗示「隔壁是通的」
2. **叙事铺垫**：暗示这里曾有通道
3. **减少建模成本**：复用门框资源

**跳板与路径多样性**：下梯子时旁边放置跳板 → 第二次经过时有路径选择多样性。

---

### 4. 火龙塔（Fire Dragon Tower）

**盾兵——新敌怪的教学编排**：

盾兵被放在**距离玩家最近的位置**，并与后方大量小怪**保持距离** → 方便玩家单独学习其战斗行为。

**光影引导 + 安全本能 = 路线控制**：

- 一条向上 → 遮挡处阴影
- 一条水平直行 → 光亮、路尽头有火把

设计者希望玩家走左侧（阴影路），但右侧（光亮路）堆了很多怪 → **玩家可能忽视光影，但绝不可能忽视自己的狗命** → 自觉走左边。

**火龙登场——心流的第一个高潮**：

> 「在经历前面的多场战斗之后，玩家的新鲜感已经逐渐丧失。因此在这里引入视听效果都极为震撼的历代传统火龙演出，使得玩家的心流进入高潮，关卡再次变奏。」

| 细节 | 设计意图 |
|------|---------|
| 火龙之前先有龙尸 | 铺垫，不让火龙的出现「平白无故」 |
| 火龙喷火烧死楼上小怪 | 引导玩家学习「龙的火焰可以用于清怪」 |
| 楼上地板烫脚 / 楼下不会 | 降低楼下推进难度 |

**非强制性锁钥解谜——首次引入**：

```
正面关卡不通 → 走支路 → 学习解锁方法（利用火龙喷火） → 破解谜题 → 推进正路
```

- 正路其实可以直接冲
- 支路做得极短（上了楼梯就是）
- 体现**前期低难度设计**
- 但悄然告诉玩家：**这个游戏的推进不是一路畅通无阻的**

> 「破解了谜题的玩家将获得一定的成就感，并且从火龙的吐息下经过会有劫后余生的庆幸。」

**洛斯里克剑骑士——区块的小Boss**：

如何告诉玩家「这是个强敌」？

| 手法 | 实现 |
|------|------|
| 缓步登场 | 体现敌怪的从容与威胁 |
| 装束更改 | 凸显形象气质的差异 |
| 简化画面 | 拆掉门框上的火把 → 视线重心集中到敌人身上 |

**第一个单向门**——流程中作者希望玩家发现的第一个单向门：

> 「单向门设计出来，就是为了让玩家**双向都触发一遍**的。只有从反向发现打不开，才有可能启发玩家：正面有遗漏的区域没有探索，从而回头再走一遍。」

**宝箱怪——为什么放在这里？**

火龙塔做成两层，却只有一个宝箱怪。为什么？
1. **两层结构 = 先行铺垫**：为后续高墙边塔同样两层、但内容丰富的塔做心理预期
2. **宝箱怪的时机**：来到这里的玩家要么刚经历骑士激战、要么刚躲过火龙火焰 → **再次处于放松时刻** → 突然插入宝箱怪 → 进一步激发情绪

---

### 5. 高墙边塔——「这段流程中最精彩的一段」

**多层引导的精密编排**：

```
进门 → 右侧高亮拾取物（优先向右）
  → 透光门框 + 火把（自然映入眼帘 → 诱导出门）
    → 木板尽头 → 向下看到二层门框 + 地板破洞
      → 暗示塔有更深层次 → 拉开空间层次
```

**关键道具火焰壶**：不仅可以引爆塔中各处的火药桶，还可以对付后续的人之脓——**道具的给予与即将面临的挑战精确匹配**（洪七公理论：毒蛇七步内必有解药）。

> 「这一段极其精彩——玩家接受了大量场景信息，获取了关键道具，但是**一切都发生得如此自然**。」

## 核心设计理论

### 1. POI 兴趣点系统

从初始塔的第一幕开始，FromSoftware 就在用 POI 引导玩家：

| POI 类型 | 示例 | 作用 |
|---------|------|------|
| 光源 | 篝火、火把、追光源 | 近程导航 |
| 远景 | 舞娘城楼蓝光、塔楼群 | 建立长期预期 |
| 运动物体 | 唯一移动的敌怪 | 最高优先级注意力 |
| 拾取物 | 高亮白光 | 激发探索欲 |

> 这和塞尔达·旷野之息的 POI 系统同源——用视觉上特异的点吸引玩家注意力，建立关卡推进的预期。

### 2. 教学式战斗编排

高墙前期的每一场战斗都是「教学关卡」：

```
观察敌人行为 → 理解机制 → 实践应用 → 奖励/惩罚
                                      ↓
                              难度递进 → 检验学习成果
```

| 教学点 | 教学方式 | 检验方式 |
|--------|---------|---------|
| 基础战斗 | 一对一简单敌人 | — |
| 提灯哥机制 | 行为动画 + 引怪演示 | 第二只提灯哥 + 三个敌怪 |
| 偷袭警惕 | 「前狼假寐」陷阱 | 后续流程的隐藏敌怪 |
| 火龙机制 | 喷火烧死楼上小怪 | 利用喷火通过楼下 |
| 锁钥解谜 | 非强制性支路 | 后续流程复用 |

### 3. 光影作为核心引导语言

这是本期最独特的发现——FromSoftware **系统性地使用光影引导玩家**：

- **追光源**：解包实锤，刻意在楼梯口放置追光源制造亮斑
- **明暗对比**：出口总是更亮、正路总是有光源
- **火把系统**：火把标记前进方向、柱子遮挡火把劝阻返程
- **保护色**：室内暗处敌怪与场景同色 → 没有提灯的敌怪更容易偷袭

### 4. 偷袭的时机哲学

偷袭不是随机放置的——每次偷袭都精确对准玩家**心理防御最低的时刻**：

| 偷袭位置 | 前置状态 | 设计意图 |
|---------|---------|---------|
| 龙石塔上层 | 刚完成学习→奖励循环 | 放松警惕 → 建立「随时有偷袭」的认知 |
| 塔内暗处 | 刚击杀显眼的提灯小怪 | 再次放松 → 构建暗处 = 危险的联想 |

### 5. 「有得有失」的支路哲学

隐藏支路不做视觉处理、支路尽头不能回头——**奖励与风险成正比**，这是贯穿整个高墙设计的原则。

## 与第二期的关系

- 第一期建立了高墙的**前期框架**（初始之塔 → 龙石塔 → 火龙塔 → 高墙边塔），引入 POI 兴趣点、教学闭环、光影引导、偷袭时机、单向门等**基础概念**
- 第二期 [[ds3-lothric-high-wall-2|高墙深处]] 在此基础上将复杂度大幅提升：多路线选择、多层结构、多敌人配置、心流节奏控制
- 两期共同构成**完整的洛斯里克高墙关卡设计全景**
