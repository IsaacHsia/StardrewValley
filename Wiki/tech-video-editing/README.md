## S1 剪辑基础

### L1 — 口播精剪与 A/BRoll 协同

**核心概念：** A-Roll（主信息轨道）+ B-Roll（叠加素材，丰富视觉感官）

**口播气口处理：**
- **剪映自动剪口播** — 右键轨道，根据语义删除字句或停顿，自动同步轨道
- **气口剪不掉** → 分割后加叠化，垫一段环境音在底部掩藏
- **长时间素材** → 用自动剪口播功能批量处理

**BRoll 核心技巧：**
- 素材预览裁剪快捷键：I + O
- 左上角另开时间线与 A-Roll 上下堆叠
- B-Roll 添加要对齐说话的节奏
- 气口无法被 B-Roll 覆盖时 → 放大 A-Roll 镜头 / 用万能 B-Roll 素材
- B-Roll 记得静音

**声音补录与处理：**
- 响度统一：全选音频后一键统一
- 声道补充
- 建议使用麦克风，防止喷麦

**字幕样式：**
- 放在视频中心下方，不要太靠近边缘
- 参考参数：不透明度 59、模糊度 7、距离 5、角度 -45

**BGM：** CTRL+B 裁剪 + 淡入淡出

### L2 — 节奏学控：混剪视频与蒙太奇逻辑

**BGM 选择与踩点：**
- 用 BGM 确定节奏主线
- 踩节拍工具：节拍 1（舒缓）/ 节拍 2（密集）
- 情绪铺垫 → 优先选择平缓、无剧烈位移的空境

**镜头组：**
- **初级** — 景别递进：大远景（氛围）→ 中景（环境关系）→ 特写（核心主体细节）
- **进阶 — 镜头拼接：**
  - 匹配剪辑：相似镜头拼接到一起，自然过渡
  - 交叉叙事（库里肖夫效应）：无直接联系的画面并置，观众自动脑补关联
  - **蒙太奇**：不同镜头按顺序和逻辑剪辑产生新意义，控制观众情绪

**切分卡点技巧：** 让镜头出现在不该出现剪辑点的地方，制造惊喜感

**转场与特效：** 在剪辑点添加转场预设；在剪辑点外添加特效

### L3 — 听觉塑造：音乐处理与音效设计

**音频修剪 — 制造尾迹：**
1. 找副歌结束的重拍切开
2. 复制两段音乐，第二段静音，拖到后方
3. 封装为音频复合片段（Option+G / Alt+G）
4. 添加回音或大厅混响
5. 修剪保留从切点向后扩散的混响尾迹

**音效添加：**
- **环境音** — 观察画面同步联想 + L-cut（声音提前/延迟画面 2-3 秒出现/消失）+ 渐入渐出
- **特殊设计音效** — J-cut 开场（向后平移所有轨道制造开场）+ 空镜低音轰鸣
- **自制音效** — 录制后用变速/音调调节编辑
- **AI 音效** — 尝试利用 AI 生成音效

### L4 — 交付与导出管理

**封面与标题：**
- 封面：在视频中选静帧，编辑封面加文字
- 标题命名规范：`年份_月份_日期_片名_分辨率_视频版本_发布平台`
- 保存结构：成片、工程、素材放一起；按导出/视频/图片/音频分好子文件夹

**导出参数速查：**

| 参数 | 说明 | 建议 |
|------|------|------|
| 分辨率 | 清晰度，不超过素材 | 与素材一致 |
| 帧率 | 流畅度 | 与剪辑草稿一致 |
| 码率 | 信息密度（越高细节越多） | 剪映推荐码率 |
| 封装 | MP4 / MOV | MP4 通用 |
| 编码 | H.264（通用）/ HEVC/H.265（压缩高） | H.264 应对多数场景 |
| 音频编码 | AAC 192~320 kbps / PCM | 普通视频 256~320 |
| 音频采样 | 48000Hz | 标准值 |

**特殊提示：** 剪映的超清画质/补帧/补分辨率不要全篇使用，只补救单段素材

## S2 进阶技术

### L1 — 运动控制关键帧与曲线运动

**关键帧基础：**
- 给素材的某个参数设置起点和终点，软件自动计算补间动画
- 关键帧往往需要组合使用（如缩放 + 位置）

**关键帧曲线（Option+K / Alt+K）：**
- 正常运动规律：缓速启动 → 加速 → 减速
- 要让画面协调，所有相关参数的曲线必须保持一致

### L2 — 动态节奏曲线变速与素材帧率

**基础变速：** 拖拽手柄拉长（慢放）/ 缩短（快放）

**补帧方法对比：**

| 方法 | 速度 | 效果 |
|------|------|------|
| 帧融合 | 快 | 易出现重影和破碎感 |
| 光流法 | 慢 | 运动显示更自然 |

**建议：** 拍摄时用高帧率（60fps-120fps）从源头解决问题

**曲线变速：** 向上拖加速 / 向下拖减速；极快到极慢的剧烈反差制造动能与焦点切换

**变速卡点：** 让素材自动跟随 BGM 变速

### L3 — 空间重组：全能抠像、蒙版合成

**智能抠像：** 一键抠像，点击 S 键开启预览

**自定义抠像：** 画笔圈出范围 → 调整笔刷 → 橡皮擦擦除 → 蓝光完全覆盖后应用

**抠像三明治（人物背后大字效果）：**
```
┌─ 背景层（主轨）───┐
├─ 文字轨道 ───────┤  ← 关键信息文字
├─ 抠像层（辅轨）───┤  ← 人物抠像
└──────────────────┘
```
适用于口播/评测中强调关键信息

**绿幕抠像（色度抠图）：**
- 取色器选取要去除的颜色
- 强度：控制抠除范围
- 阴影：修复打光不均造成的残留
- 边缘羽化 + 边缘清除：柔和边缘

**蒙版：** 先用蒙版框选主体，再绿幕抠像去除多余颜色

**混合模式速查：**
| 组别 | 效果 | 常见模式 |
|------|------|---------|
| 变亮组 | 留白，剔除黑色 | 颜色减淡、强光、变亮、滤色 |
| 变暗组 | 留黑，剔除白色 | 正片叠底、颜色加深、变暗 |
| 混合叠加 | 亮部更亮、暗部更暗 | 叠加、柔光 |
| 保留黑颗粒 | 保留黑、剔除白背景 | 线性加深、正片叠底、颜色加深 |

### L4 — 色彩科学：掌握一级调色工具

**Log 与 LUT：**
- Log 灰片保留更多画面细节
- LUT（颜色查找表）将灰片还原为正常色彩
- 不同 Log 曲线对应不同 LUT 预设

**基础调色三要素：**
- 亮度（明暗）
- 饱和度（浓淡）
- 色相（偏色方向）— 使用 HSL 调节

**进阶色轮（四区域）：**
1. 阴影
2. 中间调
3. 高光
4. 偏移

每个区域可独立调整色相 + 饱和度 + 亮度

**示波器使用：**
- **波形图** — 显示亮度分布
- **分量图** — 显示各颜色通道分布，偏色方向一目了然
- **矢量图** — 圆心到边缘距离 = 饱和度，星星飞出方向 = 偏色方向

## S3 综合实战

### L1 — 拉片解构与文字追踪

**拉片方法论：**
- 镜头时长由画面信息密度决定
- 第一幕要保证留存率 → 信息密度不够就快速过渡
- 第二幕开始提供更多信息，时长拉长
- 文字必须有大小层级：辅助信息小，重点信息大
- **踩梯子技巧**：每一次让观众对下一次有预期，但下一次超过预期。化繁为简，减少转场/BGM

**文字追踪：**
- 加阴影 + 加描边（粗细≈13）增强易读性
- 追踪框的十字点放在不易消失的特征点上
- **先完成粗剪 + 再添加文本和追踪**（追踪消耗算力）

**动态效果：**
- **数字增加** — 2 帧为单位的文字轨道切分，逐段修改数字
- **滚动动画** — 出入场动画衔接 + 镜面蒙版限制区域

### L2 — 进阶平面追踪

1. 文本轨道变复合片段 → 编辑文字内容
2. 开启平面追踪，框选追踪物体（选画面中占比最大的帧开始追踪）
3. 物体消失时 → 切分轨道，删除后续段落，加渐隐出场
4. 文字拉伸变形 → 关闭等比缩放，调整宽度/高度
5. 错误透视 → 平面追踪下的调整素材角度
6. 添加特效 → 进入复合片段，特效加在文字轨道上

### L3 — 多机位剪辑

**对齐方法：**
- **音频对齐** — 根据声音波形自动检测对齐
- **时码器** — 给所有机位打上统一时间码

**核心原则：** 将镜头对准正在说话的人

**粗剪流程：**
1. 选中素材 → 新建多机位片段
2. 拖动进度条到切换点 → 点击播放器中的目标素材完成切换
3. 想切换机位 → 选中片段，在播放器中选新机位

**完善：** 添加角标/人名条 → 提取金句单独使用

### L4 — 时钟理论应用

**长视频结构（13~23 分钟 / 50 分钟+）：**
- **开头**：抛出三个最重要的关联问题当钩子，产生共鸣和好奇
- **引入**：揭示主题，告诉观众要做什么
- **预告**：混剪 + 上升音乐 + 夸张表情，满足部分预期并超过预期
- **线性叙事**：快速进入重要议题
- **波峰理论**：20 分钟安排 10 个波峰，保证兴趣锁定
- **结束要快**

**时钟理论：** 将视频长度当成周长画一个圆，标出 0、3、6、9 点位置 → 这些位置是观众最容易退出的点，必须安排刺激

**计时器效果制作：**
1. 定格 1 帧素材作为静止帧
2. 拉长到 60s
3. 黑幕素材对齐 + 蒙版圆角
4. 蒙版描边 + 阴影
5. 降低不透明度到 45%
6. 复制多个框，保持间距（Shift 锁定 Y 轴）
7. 文字轨道放入蒙版内
8. 文本翻页效果 → 时间错位增加层次感

**分段剪辑：** 长视频分前中后期，每段独立剪辑打磨，用音乐引导情绪（前期好奇 → 中期紧张 → 后期疲惫挣扎）

### L5 — Vlog 的剪辑结构与色彩

**文件管理：**
- 总文件夹命名：`日期+具体内容`
- 子文件夹分类 + 数字序号自动排序（01素材、02音乐...）
- 视频原始文件名保留相机默认命名

**让 Vlog 有主线 — 三段式创作法：**
1. **乱序堆叠** — 时间线上随意放素材，用箭头标注呼应关系
2. **正式思维导图** — 基于乱序整理，确立主题
3. **分段式剪辑** — 每段独立打磨有趣，再衔接拼装

**AI 辅助提效：** 利用剪映提取视频文字 → 大语言模型（豆包等）总结、重编、提取有意义状态

**片段串联：**
- **旁白过渡** — 段落间插入后期画外音承上启下
- **节奏点衔接** — B-Roll 混剪 + 音乐拉升
- **经典套路**：旁白铺垫 → 旁白停止 → 音乐起，画面跟节奏点拉升

**进阶调色 — RGB 曲线：**
- 横轴：原亮度（左暗右亮）
- 纵轴：调整后亮度（下暗上亮）
- 45° 斜线 = 无变化
- **S 型曲线**：暗部下压 + 亮部上提 = 增加对比度
- 红绿蓝单通道曲线可调色彩平衡

**多场景统一色彩：** 色彩克隆工具 → 定位已调色帧 → 自动匹配风格

**智能调色工具：** 快速出片参考方向，但质感不如手动精细

**分级导出策略：**
- **Demo 导出** — 粗剪后低码率导出，回看/甲方审核
- **成片导出** — 最终修改完成后导出

## 关键公式与原则

**剪辑节奏公式：** BGM 定调 → 踩点 → 景别递进 → 匹配剪辑/交叉叙事 → 卡点破格

**口播工作流：** 自动剪口播 → B-Roll 覆盖气口 → 响度统一 → 字幕 → BGM

**导出决策树：** 素材分辨率 < 剪映推荐 → 维持原分辨率；帧率 = 草稿；编码 H.264 通用

**Vlog 创作法：** 乱序堆叠 → 思维导图 → 分段剪辑 → 旁白串联 → 节奏点衔接
