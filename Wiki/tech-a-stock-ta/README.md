## 知识体系总览

### 第一层：单根K线（基础信号）

单根K线是市场行为的「快照」—— 极端形态出现在趋势末端时具有反转意义。

| 信号 | 位置 | 含义 |
|------|------|------|
| 长红线（低档） | 下跌末端 | 大资金入场启动信号 |
| 长红线（高档） | 上涨末端 | 多头耗尽警告 |
| 长红突破 | 箱体震荡后 | 趋势确认，放量真/缩量假 |
| 长红跌破 | 支撑位破位 | 止损盘启动，加速下跌 |
| 长黑线（高档） | 上涨末端 | 直接清仓 |
| 长黑线（低档） | 下跌末端 | 非理性下跌，接近底部 |
| 上吊线 | 高位 | 空方进攻，多方松动，需次日确认 |
| 铁锤线 | 低位 | 与上吊线相同形态，位置不同 |
| 流星线 | 高位 | 多方最后一次进攻失败 |
| 倒装铁锤线 | 低位 | 多方开始获得进攻能力 |

### 第二层：双K线组合（确认/预警）

从单根「快照」升级为多日「视频」，记录力量变化的过程。

| 组合 | 方向 | 强度 | 信号类型 |
|------|------|------|----------|
| **看涨吞没** | 底部反转 | ⭐⭐⭐⭐⭐ | 完成时（立即执行） |
| **看跌吞没** | 顶部反转 | ⭐⭐⭐⭐⭐ | 完成时（立即执行） |
| **看涨孕线** | 底部预警 | ⭐⭐ | 进行时（需后续确认） |
| **看跌孕线** | 顶部预警 | ⭐⭐ | 进行时（需后续确认） |
| **刺透形态** | 底部反转 | ⭐⭐⭐⭐ | 进行时（已切换过半） |
| **乌云盖顶** | 顶部反转 | ⭐⭐⭐⭐ | 进行时（已切换过半） |

**力量切换谱系**：孕线（力量衰竭）→ 刺透/乌云（力量切换过半）→ 吞没（力量完全反转）

### 第三层：技术指标

- **7轨布林线**：7条轨道标记从极端超买到极端超卖的完整区间，第3轨为趋势分水岭。

### 第四层：交易哲学框架

「交易之道」构建了一套完整的强趋势股交易系统：

1. **强趋势股三层分类**：强/弱趋势 × 脉冲/长趋势 × 主升/震荡/主跌阶段
2. **追高 vs 低吸**：两种买点对应不同的交易预期与处理方式
3. **主动意识**：买入前设定期望剧本，买入后验证而非解释
4. **滚动操作**：趋势从加速转入震荡后，降仓保留底仓+低位加回
5. **时间周期有效性**：单一状态5-7天极限，同一信号重复3次以上警惕失效
6. **大五人格 × 交易适配**：基于性格选择交易模式的框架
