# 7轨布林线

> **来源**: [[A股/上课笔记/7轨布林线]] | ← [[README]]

---

## 轨道定义

7轨布林线包含从极端超卖到极端超买的完整区间，共7条轨道：

| 轨道 | 位置 | 状态 | 操作建议 |
|------|------|------|----------|
| **顶轨** | ⬆ 最高 | **极端超买** | 大概率出现回调，准备减仓/做空 |
| **一轨** | ⬆ 次高 | 中度超买 | 考虑减仓操作 |
| **二轨** | ⬆ 偏高 | 轻度超买 | 以观望为主 |
| **三轨** | ➡ 中间 | **趋势分水岭** | 方向判断基准 |
| **四轨** | ⬇ 偏低 | 轻度超卖 | 以观望为主 |
| **五轨** | ⬇ 次低 | 中度超卖 | 可分批建仓 |
| **底轨** | ⬇ 最低 | **极端超卖** | 大概率出现反弹，准备建仓/做多 |

---

## 核心用法

### 三轨 — 趋势分水岭

第3轨是判断趋势强弱的核心分水岭：
- 价格在**三轨以上**运行 → 强势区间
- 价格在**三轨以下**运行 → 弱势区间
- 三轨附近是趋势转换时的重要博弈区域

### 极端位置

- **顶轨附近**：极端超买，回调概率大，不宜追高
- **底轨附近**：极端超卖，反弹概率大，不宜杀跌

### 超买超卖梯度

```
顶轨 —————————— 极端超买 ← 不可追高，准备减仓
 一轨 ————————— 中度超买 ← 开始减仓
 二轨 ————————— 轻度超买 ← 观望
 三轨 ————————— 分水岭   ← 判断方向
 四轨 ————————— 轻度超卖 ← 观望
 五轨 ————————— 中度超卖 ← 开始分批建仓
底轨 —————————— 极端超卖 ← 不杀跌，准备反弹
```
