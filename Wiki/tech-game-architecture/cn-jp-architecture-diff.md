# 中日建筑屋顶区分 — 游戏场景美术指南

> **来源**: [Bilibili 视频 — 鱼白施行《游戏是如何区分中日建筑的？》](https://www.bilibili.com/video/BV1Z2jJ68EP9/)
> **受众**: 游戏场景美术师、建筑爱好者
> **核心问题**: 中式与日式在屋顶上的显著区别，帮助分辨与创作场景

---

## 一、中式建筑基础构型

中式建筑 = 一方盒子 + 坡屋顶。根据屋顶与房间的衔接关系，分为两大类：

### 1.1 四面屋檐（屋顶完全压在房间上）

| 类型 | 描述 | 等级 | 用途 |
|------|------|------|------|
| **庑殿**（五殿顶） | 放躺的三棱柱，上面一条棱缩短 | 最高（无级顶） | 皇室、贵族、楼阁、庙宇 |
| **歇山**（九级顶） | 庑殿半山腰加"腰带"，使腰部与顶部同宽 | 高（九级顶） | 同上 |

- 五和九在古代表尊贵，平民不可使用
- 用料大、造价高，平民也造不起

### 1.2 仅有前后屋檐（无侧向屋檐）

根据屋顶与山墙的关系：

| 类型 | 特征 | 背景 |
|------|------|------|
| **硬山** | 山墙比屋顶高，两侧山墙"夹住"屋顶 | 后期砖石科技发展，山墙防水防火，以徽派建筑为代表 |
| **悬山** | 屋顶比山墙高，两侧延伸出去悬在山墙外 | 早期夯土墙怕水，用悬山保护山墙 |

### 1.3 卷棚（形状修饰符）

- **不是**独立屋顶类型，而是一种**弧形形状**
- 可与各类屋顶组合：卷棚歇山、卷棚悬山、卷棚硬山
- 多用于偏殿和园林，不太正式

### 1.4 抱厦（Baoxia / Attached Porch）

主殿前后左右的小空间，两种连接方式：

| 类型 | 特征 | 用途 |
|------|------|------|
| **正交式抱厦** | 小房间正脊方向与抱厦所连墙面垂直 | 正式庙宇、大殿、楼阁（如霍州鼓楼、隆兴寺摩尼殿） |
| **平行式抱厦**（勾连搭） | 小房间正脊与所连墙面平行 | 世俗化场景：园林、院落大院 |

**关键结论**：正交式抱厦**只有歇山抱厦一种形式**，不存在悬山和卷棚做法。

> 📌 中式楼阁高层抱厦大多为 **半封闭**（柱子围合，可见内部），且下方有下层抱厦或屋檐承接结构。

## 二、日式建筑对应关系

### 2.1 屋顶对应词汇

日式词缀不叫"顶"而叫"**造**"（或"**妻**"）：

| 中式 | 日式 | 说明 |
|------|------|------|
| 庑殿顶 | **入母屋造**（Irimoya-zukuri） | — |
| 歇山顶 | **入母屋造** | 与庑殿同词，靠上下文区分 |
| 悬山顶 | **切妻造**（Kirizuma-zukuri） | — |
| 硬山顶 | ❌ **日本无典型硬山顶** | **中日第一大区别** |

### 2.2 破风（Hafu）— 日式屋顶装饰核心

**破风** = 屋顶上的山面装饰，是日式建筑的核心特征，中式建筑中没有。

| 类型 | 特征 | 备注 |
|------|------|------|
| **千鸟破风**（Chidori-hafu） | 在平整屋顶上单独加的三角形山面装饰 | ❌ 中式建筑中几乎不存在（仅云南丽江木府万卷楼一例，且为1996年重建） |
| **入母屋破风**（Irimoya-hafu） | 对标歇山的侧面，体量最大，天守阁上最大三角山面 | 相当于把歇山顶用作装饰 |
| **切妻破风**（Kirizuma-hafu） | 千鸟破风去掉底边，只剩人字形山面 | 像悬山的侧面 |
| **唐破风**（Karahafu） | 切妻破风的弧形变体，类似日式"卷棚悬山" | ⚠️ **不是**中式卷棚！营销号常混淆 |

> **核心判断**：千鸟破风是**纯粹的日式做法**。查阅1200页中国建筑史、约3000张建筑图纸，未发现千鸟破风的中式实例。古画中的类似案例（如明代安正文《黄鹤楼图》）存在严重杜撰嫌疑，不宜作为考据。

### 2.3 日式抱厦特征

日式抱厦常与破风强关联：

- **切妻破风抱厦**（正交式人字形悬山抱厦）
- **千鸟破风抱厦**
- **入母屋破风抱厦**
- **唐破风抱厦**

其中，**正交式唐破风抱厦**和**正交式切妻破风抱厦**是日本独有的做法，在中式建筑中完全找不到实例。

> 📌 日式天守阁高层抱厦为 **全封闭**（实墙围合），且下方可以**完全悬空**，不需要承接结构。这与中式楼阁的高层半封闭抱厦形成鲜明对比。

## 三、中日屋顶装饰核心差异总结

| 维度 | 中式 | 日式 |
|------|------|------|
| **硬山顶** | 常见（徽派建筑等） | 无 |
| **千鸟破风** | ❌ 不存在（千余页资料无实例） | ✅ 常见做法 |
| **唐破风** | ❌ 不存在 | ✅ 常见（神社、寺庙、城堡） |
| **正交式卷棚/悬山抱厦** | ❌ 不存在 | ✅ 常见（唐破风抱厦、切妻破风抱厦） |
| **高层抱厦封闭性** | 半封闭（柱围合） | 全封闭（实墙围合） |
| **抱厦下方结构** | 必有承接（下层抱厦或屋檐） | 可完全悬空 |

## 四、案例解剖：原神·璃月（以倭代唐的典型反面教材）

视频作者以原神璃月地区的建筑为反面案例，指出大量日式元素被误用于"中式"场景：

| 建筑 | 问题 |
|------|------|
| 茂才公府邸 | 歇山抱厦上堆叠两层唐破风抱厦 |
| 粤海亭 | 轩唐破风大门 + 屋顶复制粘贴 |
| 茂才公府对面小亭 | 入母屋造 + 两侧千鸟破风 + 四面唐破风（比日式唐门还多） |
| 空中连廊 | 歇山顶上凭空加三角山面（千鸟破风）→ 大量复制粘贴 |
| 神社式建筑 | 入母屋造 + 千鸟破风 + 封闭式唐破风抱厦（仿天守阁高层） |
| 璃月港楼阙 / 花船 | 封闭式切妻破风抱厦 |
| 黄金屋 | 典型切妻破风抱厦 |
| 铁匠铺 | 切妻造改入母屋造 → 微缩版天守阁 |

> **作者观点**：原神制作组并非主观"以倭代唐"，而是**不认真学、不尊重建筑文化、胡乱设计**。解决方案是做减法——加法越繁杂，逻辑上越倾向于日式；做减法才能掌握中式华美大气庄严的内核。

## 五、对游戏美术师的启示

1. **学基础**：熟练理解庑殿、歇山、悬山、硬山、卷棚、抱厦这六大核心概念
2. **知界限**：千鸟破风、唐破风、切妻破风是日式标志，勿用于中式场景
3. **做减法**：中式建筑之美在屋顶曲线本身的灵动与完整，不在额外装饰
4. **弃古画**：古画（尤其宫廷/界画）多属想象创作，不宜做建筑学术考据
5. **辨结构**：中式台梁式承重体系限制屋顶改动；日本小规模组/桁架结构容忍更多变化
