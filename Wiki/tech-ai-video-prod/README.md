# AI 辅助自媒体视频制作工作流

> **来源：** Bilibili 映像同好会《为什么 Mac 是 AI 时代自媒体的版本答案？》
> **摄取日期：** 2026-07-19
> **核心主题：** 一个完整 AI 赋能的自媒体视频制作流程——从策划、拍摄到后期，各环节如何用 AI 提效，以及为什么 macOS 是目前的最佳承载平台。

---

## 总览

本文梳理了面向独立视频创作者的 **AI 原生制作管线**，覆盖视频生产的完整生命周期：策划 → 拍摄 → 后期。核心观点是 Mac 的 POSIX 基因 + 雷电生态 + 编解码硬件 + 软硬集成度，使其成为 AI 时代自媒体创作的最省心选择。

---

## 各环节详解

### 1. 策划与文案：AI 辅助选题与分镜

当前阶段 AI 的角色是**辅助而非替代**——核心表达仍由创作者手打或语音输入，AI 用于：

- **选题方向梳理**：AI 帮助梳理结构、整理思路
- **自动分镜脚本生成**：通过提前制作的 **Claude/Codex agent（分镜头助手）**，将完整文案丢入后自动：
  - 分段文案
  - 生成对应分镜头类型与内容
  - 输出整齐划一的表格
- **效果**：分镜从 1-2 天缩短到半小时以内；拍摄时逐项打勾确认，避免漏拍/重拍

> 该分镜头 agent 已在 GitHub 开源。

### 2. Mac vs Windows：AI 工具生态优势

核心论证——**Mac (Unix/POSIX) 在 AI 工具生态上具有结构性优势：**

| 维度 | macOS | Windows |
|------|-------|---------|
| 底层兼容 | 与 Linux 同属 POSIX 标准，命令行工具和包管理系统完善 | 底层与 AI 开发存在隔离 |
| Agent 运行 | AI agent 直接在终端帮写命令、改文件、装依赖、跑脚本，运行流畅 | 需额外折腾环境配置 |
| 实测案例 | 达芬奇 MCP — AI 一遍配好正常运行 | 达芬奇 MCP 缺 Windows 适配，需修 Python 环境变量、盘符斜杠、编码冲突（JIS/UTF-8）、中文路径等，耗费数小时 |

**结论：** 如果要深度使用 AI agent 类工具，强烈建议避开 Windows。

### 3. 拍摄设备与工作流

AI 无法替代拍摄环节，但 AI 生成的分镜表格显著提高了拍摄效率。

**设备配置：**

| 设备 | 用途 |
|------|------|
| 松下 GH6 | A/B 位主力拍摄 |
| iPhone 15 Pro | 俯视角 + 副机位（优势：轻便、随时可录） |
| 阿卡西斯双协议雷电硬盘盒 | 相机/手机直接录制到硬盘，免去拷卡时间 |

**工作流亮点：**
- iPhone 素材通过 AirDrop 传到 Mac
- GH6 和 iPhone 15 Pro 均支持外接硬盘直录
- 硬盘盒采用英特尔雷电芯片 + 额外 USB 芯片，兼容性好，带主动散热
- 拍摄完直接插 MacBook 开始剪辑，无需等待拷卡

### 4. 后期流程：Mac 传统强项

**设备：** M1 Pro MacBook Pro（5 年前初代，升级 26 系统后依然流畅）

**桌面配置：**
- 主屏：剪辑
- 竖屏：参考文案
- MacBook 屏幕：监看 / 管理素材
- 阿卡西斯 21 口雷电 4 拓展坞：一根雷电线连接所有外设（2 台显示器、2.5G 网线、耳机等）
- NAS 存放素材，2.5G 网口满足 4K 剪辑需求
- 达芬奇多端适配，工程文件可在 Mac 或 PC 间无缝切换

### 5. AI 动效与字幕处理

**动效制作——Codex + Remotion：**
- 传统方案：AE 古法手搓
- AI 方案：用 Codex 结合 **Remotion**（基于 Web 的动效框架），根据文案自动生成动效视频
- 适合简单动效；复杂效果（视觉同步性要求高）仍手搓

**字幕处理——达芬奇脚本：**
- 用 Codex 编写达芬奇脚本，自动处理字幕格式优化和校对
- 降低字幕处理的重复劳动

**其他探索：**
- 自动口播剪辑（Auto Cut）skill — 计划研究

### 6. 封面与元数据自动化

- **封面设计：** 用 GPT（DALL-E/ImageGen）生成封面参考图 → 手动挑选 + 微调一版
- **元数据生成：** 让 agent 通过 **MCP** 读取字幕或工程文件，自动生成：
  - 视频简介
  - 分段标签
  - BGM 信息

## 关键启示

1. **AI 不是替代创作者，而是压缩重复劳动的占比** — 分镜时间从 2 天→30 分钟，字幕/动效/元数据自动化
2. **平台选择影响 AI 工具使用成本** — macOS 的 POSIX 兼容性带来天然优势，PC 适合 3D 渲染等重型任务
3. **AI 工作流的核心是把人的创意 + AI 的效率 + 硬件的可靠串在一起** — Mac 是串联一切的「创作前台」
4. **MCP 是关键集成技术** — 通过 MCP，AI 可以直接读写工程文件、调用软件，实现从前到后的自动化
