# 商业航天全产业链 — 从航天工程到航天工业

> 核心叙事：商业航天正从「工程验证时代」进入「万星组网、批量制造、规模运营」的航天工业时代。信息基础设施正在从地面向太空延伸。

---

## 1. 产业概况

### 1.1 中国商业航天十年历程

- **2015年** → 商业航天元年：国家民用空间基础设施中长期发展规划出台，民营资本被允许进入航天主战场
- **2015-2024** → 早期验证阶段：技术验证、型号验证、商业模式验证，低频次、项目制
- **2025年** → 分水岭：从实验阶段进入**万星组网、批量制造、规模运营**新阶段
- **2026年** → 商业航天上市元年 + 密集验证期（可回收火箭首飞、太空算力在轨验证）

### 1.2 本轮爆发的四重拐点

| 拐点 | 核心内容 | 关键指标 |
|------|----------|---------|
| **政策拐点** | 顶层设计→专项规划→基础设施→地方产业基金，完整政策体系形成 | 北京/上海/无锡/杭州等多地设立产业基金 |
| **技术拐点** | 可回收火箭、星间激光通信、星载AI抗辐射计算、太空电源热控同步成熟 | 可回收火箭2026年8-9月密集首飞窗口 |
| **成本拐点** | 可回收火箭+卫星批量化制造推动成本曲线变化 | 目标：~200美元/公斤入轨成本 |
| **需求拐点** | 通信补充、遥感监测、卫星物联网、AI算力四大需求清晰化 | AI是最大新变量——天数天算、在轨边缘计算 |

---

## 2. 核心子赛道

### 2.1 太空算力（本轮最强叙事）

太空算力是商业航天下一个10-30年的想象空间。核心逻辑：地面AI算力需求爆发 → 地面能源/土地/散热受限 → 太空成为新解决方案。

**四大技术瓶颈：**

| 瓶颈 | 问题 | 技术路线 |
|------|------|----------|
| **能源供应** | 卫星功率需从kW级→100kW级 | ROSA超柔性太阳翼 + 钙钛矿/单晶硅叠层电池 |
| **热管理** | 太空真空环境只能靠辐射散热 | 环路热管→泵驱两相流体回路→柔性可展开辐射器 |
| **抗辐射计算** | 宇宙射线导致芯片数据错误 | 宇航级抗辐射芯片 vs 商规芯片+系统容错 |
| **星间通信** | 卫星间需高速组网 | 激光星间链路（目标400Gbps→Tbps级） |

**国内玩家生态：**

- **国家队/科研机构**：浙江实验室（三体星座12星入轨）、北邮、中科天算
- **商业旗舰**：国星宇航（星载AI）、轨道晨光（16MW太空数据中心愿景）、东方天算
- **卫星制造配套**：寻天谦和（1000颗算力星座规划）、热塑科技（热控/液冷）
- **创业公司**：太空字节（太空存储，216星规划）、星测未来

### 2.2 卫星通信星座

低轨卫星通信是空天一体化网络的底座。SpaceX Starlink 是绝对标杆：

| 指标 | Starlink 现状 | 中国对比 |
|------|---------------|----------|
| 在轨卫星 | ~9,600颗 | 中国总计~1,200颗（星网~160颗+千帆~162颗） |
| 用户数 | 1,030万（2026Q1） | 尚未大规模商用 |
| 覆盖国家 | 164国 | 国内为主 |
| 时延 | ~25ms | 仍在建设中 |
| 技术代际 | V2（96Gbps/星）→V3（1,024Gbps/星） | 模组相控阵为主 |

**中国星座规划：** 已向ITU提交约20万颗卫星规划申请，ITU规则带来时间压力（2年内部署15%，5年内57%，7年内100%）。

### 2.3 可回收火箭

**技术路线对比：**

| 路线 | 代表 | 材料 | 优势 |
|------|------|------|------|
| **不锈钢+氩弧焊** | SpaceX Starship / 建源科技 | 不锈钢（低温强度提升3-4倍） | 成本低、工艺简单、耐高温、适合回收复用 |
| **铝合金** | 传统路线 | 铝合金/碳纤维 | 成熟但产线效率低（1发/年/线） |

**回收方式：** 海上回收为主（SpaceX 84%回收使用驳船），中国沿海发射场（文昌/烟台/阳江/上海）具备地理条件。

**成熟路径：** 首飞入轨 → 首次回收验证 → 连续回收成功 → 快速翻修 → 重复发射 → 成本显著下降 → 发射节奏稳定提升

### 2.4 太空态势感知（SSA）

低轨卫星从千颗→万颗级别后，太空交通管理成为刚需。类比：SSA是太空中的GPS。

**技术路径：** 地面光学 + 地面雷达 + 天基观测，地基为主、天基为辅。

**国内龙头：** 开运集团（对标美国TLE体系），首颗商业SSA卫星已发射（2025年9月），计划5年108颗，全球站点部署，数据日更新。

### 2.5 航天测控（TT&C）

从「卫星后台客服」升级为「太空资产管理中枢」。商业航天中难得的**持续性现金流水**赛道。

**主要公司：** 新异空间（580+颗卫星、15万+次测控服务、99.8%成功率）

**核心逻辑：** 卫星全生命周期都需要测控，契约型收入模式，天然高门槛（工程经验+全球站网）。

### 2.6 太空光伏

太空算力的能源基础。当前三结砷化镓电池成本~10-20万元/㎡，未来需向钙钛矿/叠层方向迭代。

**产业融合机会：** 中国是全球最强光伏产业链国家，地面光伏能力可向航天延伸。

## 3. 中美路径对比

| 维度 | 美国（SpaceX） | 中国 |
|------|---------------|------|
| 驱动模式 | 资本驱动、技术创业、硅谷工程文化 | 战略自主+举国体制+产业协同 |
| 核心路径 | 单一公司垂直整合（火箭→卫星→网络→AI） | 产业集群（国家队+商业公司+科研院所+地方政府） |
| 地面禀赋 | 能源/通信基础设施相对不足，倒逼太空叙事 | 地面基础设施极强，太空路径更务实 |
| 太空算力路线 | 大规模集中式轨道AI数据中心 | 先做分布式算力星座验证+在轨边缘计算 |
| 估值逻辑 | 「n for one」平台溢价（太空+链接+AI） | 各环节独立估值，整体产业协同 |

## 4. SpaceX IPO 分析（2026年6月）

**发行规模：** 全部增发（无老股转让），募资~750亿美元，估值1.75万亿美元
—— 有史以来最大IPO，是阿里巴巴的3倍+
**三根支柱估值框架：**

1. **太空（2002激活）**：发射能力底座，累计650次发射，全球80%+入轨质量
2. **链接（Starlink）**：现金流引擎，1,030万用户
3. **AI（2023激活）**：远期期权，X+Grok+XAI+SpaceX算力整合

**核心叙事「n for one」：** 认为自己不是众多公司中的一家，而是独一无二的太空信息基础设施平台。

## 5. 投资框架

### 两条主线

| 主线 | 内容 | 确定性 |
|------|------|--------|
| **星座配套放量** | 新网+千帆星座起量带动通信载荷/相控阵天线/星间激光/热控/电源/测控 | 较高（近期订单释放） |
| **前瞻性主题** | 太空算力、态势感知、太空资产管理、在轨服务、地月空间经济 | 较低但想象空间巨大 |

### 方法论

- 偏好「0.5→1」阶段公司（已有成熟模式/初步客户验证，未真正放量）
- 中国路径强调产业生态构建（帮助被投企业对接星座客户、进入国家队供应链）
- 关注制造业龙头向航天延伸的第二增长曲线
