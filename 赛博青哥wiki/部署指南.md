## 安装清单（跟着做就行，一步一图）

不需要懂代码。每一步都是一个下载链接 + 双击安装。装完的可以跳过。

> 💡 怎么知道装没装过？按 `Win + R`，输入 `cmd`，回车。在弹出的黑窗口里输入 `python --version`。如果显示版本号就是装了，显示「不是内部命令」就是没装。

### 1. 安装 Python（必须）

1. 打开浏览器，访问：**https://mirrors.huaweicloud.com/python/3.12.9/python-3.12.9-amd64.exe**
2. 下载后双击安装
3. ⚠️ **第一屏一定要勾选底部的「Add Python to PATH」！**
4. 点击 Install Now，等待完成

### 2. 安装 Node.js（必须，Claude Code 需要）

1. 访问：**https://registry.npmmirror.com/-/binary/node/v22.12.0/node-v22.12.0-x64.msi**
   （备用：**https://mirrors.huaweicloud.com/nodejs/v22.12.0/node-v22.12.0-x64.msi**）
2. 下载后双击安装，一路下一步

### 3. 剩下的交给 Claude Code

装好 Claude Code 之后，你直接跟它说：

```
帮我装 Git
帮我装 ffmpeg
帮我部署赛博青哥
```

它会自动检测、自动安装、自动配置。你不需要手动操作。

## 二、准备工作：获取 DeepSeek API Key

### 2.1 注册 DeepSeek

1. 打开浏览器，访问 **https://platform.deepseek.com**
2. 点击右上角「登录」，用手机号注册
3. 登录后进入开发者平台

### 2.2 创建 API Key

1. 左侧菜单点击 **「API Keys」**
2. 点击 **「创建 API Key」**
3. 输入一个名字（比如「赛博青哥」）
4. 复制生成的 Key（**只显示一次！马上保存！**）
5. 在「用量信息」页面充值（建议先充10 元）

> ⚠️ 把 API Key 保存到记事本里，后面要用。

## 三、安装 Claude Code

### 3.1 Mac 用户

打开「终端」（在启动台搜索「终端」），输入：

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

### 3.2 Windows 用户

1. 确认 Node.js 已经安装（前面清单第 2 步）
2. 按键盘 `Win + R`，输入 `cmd`，回车
3. 在命令行中输入（使用淘宝镜像加速）：

```bash
npm install -g @anthropic-ai/claude-code --registry=https://registry.npmmirror.com
```

### 3.3 配置 DeepSeek 为后端

Claude Code 默认用 Anthropic 的模型。你要切换到 DeepSeek。

参考 DeepSeek 官方文档：**https://api-docs.deepseek.com/zh-cn/quick_start/agent_integrations/claude_code**

按照文档中的说明，配置环境变量。



### 3.4 验证安装

在终端/命令行输入：

```bash
cd D:\BaiduNetdiskDownload\赛博青哥wiki[这里需要替换为你电脑上的实际目录]
claude
```

如果出现 Claude Code 的界面，说明安装成功。输入 `/exit` 退出。

## 七、你只需提供

### 8.1 DeepSeek API Key

第二步就已经有了。

### 8.2 B 站 Cookie（第一次需要，之后过期了再更新）

> ⚠️ 这一步最关键。Cookie 就是你浏览器的「登录身份证」，脚本用它来模拟你登录 B 站。

#### 第一步：打开 B 站并登录

用 **Chrome 或 Edge** 浏览器打开 **https://www.bilibili.com**，确保已经登录了你的 B 站账号。

#### 第二步：打开开发者工具

按键盘上的 **`F12`**。浏览器右侧或底部会弹出一个面板。

#### 第三步：复制一个带 Cookie 的请求

1. 在开发者工具面板中，点击顶部的 **`Network`**（网络）标签
2. 键盘按 **`F5`** 刷新当前页面
3. 左侧会出现很多请求，在顶部的搜索/过滤框中输入 **`api.bilibili`**
4. 随便点击一个请求（比如 `nav` 或 `feed/space`），确保右边出现该请求的详情
5. 在该请求上 **右键 → Copy → Copy as cURL**（复制为 cURL）

#### 第五步：发给 Claude Code

打开 Claude Code，直接把复制的内容粘贴过去：

```
这是我复制的 cURL，帮我更新 Cookie 到脚本里：
curl 'https://api.bilibili.com/...' -H 'Cookie: ...' ...
```

Claude Code 会自动从 cURL 中提取 Cookie，填到 `fetch_blogger.py` 和 `fetch_comments.py` 里。

> 💡 就一步操作：右键 → Copy as cURL → 粘贴给 Claude Code。不用自己找哪个字段、不用手动拼。
>
> ⚠️ Cookie 一般 **1-2 周过期**。过期后脚本会提示「登录失败」，重新按上面的步骤操作一遍即可。

## 十、常见问题

### Q1：Cookie 过期了怎么办？

B 站 Cookie 一般 1-2 周过期。过期后脚本会提示「登录失败」——重新按第七章的方法获取一次 Cookie，告诉 Claude Code「帮我更新 Cookie」即可。

### Q2：脚本报错了怎么办？

直接把错误信息复制给 Claude Code：「这个脚本报错了，帮我看看什么原因。」

### Q3：被 B 站风控了怎么办？

如果你短时间内频繁拉取或刷新了清枫的页面，B 站会暂时封禁你的 IP（通常 30-60 分钟自动解除）。等一等就好。清掉浏览器的 B 站 Cookie，重新登录，也能加速解封。

### Q4：如何更新赛博青哥项目？

自己演化吧 想实现什么功能就问claude code

### Q5：视频转录为什么这么慢？

视频转录（transcribe_videos.py）需要下载 Whisper 模型（约 1.5GB），而且用 CPU 转录 20 分钟的视频大约需要 30-60 分钟。如果有 NVIDIA 显卡，脚本会自动使用 GPU 加速。没有显卡就放慢等。

其实还有另外一种选择

你可以把视频下载下来，去找千问让千问帮你弄（具体可以搜ai 我也是很久之前用过一次了）

### Q6：DeepSeek API 不够用怎么办？

在 platform.deepseek.com 充值即可。日常使用（每天 ing + 几次 qry/sug）每月大概消耗几十元。
