# AI硬件梯队定位

> 本页面追踪博主对AI硬件产业链内部的梯队分层和时序策略。博主在 2026-06-17 晚间视频中首次系统给出此框架：不是所有AI硬件方向都能同时做，需要根据涨幅、催化节奏和安全边际进行梯队切换。

---

## 框架来源

博主在 2026-06-17 晚间专题（陆家嘴论坛后）首次明确提出AI硬件的三层梯队定位。背景：PCB和光连接已经炒了一个月以上，涨太多；博主此前（6/5加仓至5成时）已经开始提示结构性切换。陆家嘴论坛超预期后，国产替代+AI硬件方向明确，但内部需要去弱留强。

*来源：[[2026-06-17]] 晚间专题*

---

## 三层梯队体系

### 第一梯队：PCB + 光连接

| 属性 | 内容 |
|------|------|
| 方向 | PCB（印制电路板）、光连接（光模块/MPO/光互连） |
| 产业定位 | 全球AI算力基础设施的物理连接层，美股映射最直接 |
| 策略 | **等更安全时再做** — 已炒一个月以上、涨太多 |
| 代表标的 | 太辰光、东山精密、光迅科技、中际旭创、天孚通信等 |

**博主判断**：第一梯队方向本身没问题，产业趋势确定性高，但短期位置不合适。等回调到更安全的位置再介入。

### 第二梯队：光芯片 + PCB整版 + MACC

| 属性 | 内容 |
|------|------|
| 方向 | 光芯片（CW光源/EML/VCSEL）、PCB整版（高阶HDI/封装基板）、MACC（多芯片先进封装互联） |
| 产业定位 | 光通信核心器件+PCB高端化升级，国产替代逻辑 |
| 策略 | **后续再做** — 等待更好的入场时机 |
| 代表标的 | 永鼎股份（CW光源）、炬光科技（CPO边缘耦合）、长光华芯（EML）、芯碁微装（LDI设备） |

**博主判断**：第二梯队产业逻辑成立，但与第一梯队有联动效应，等第一梯队调整到位后再同步布局。

### 第三梯队 🔥：存储设备 + 光纤光缆（当前重点方向）

| 属性 | 内容 |
|------|------|
| 方向 | 存储设备（薄膜沉积/清洗设备/光刻胶）、光纤光缆 |
| 产业定位 | 长鑫/长存IPO→设备采购放量（设备链），全球缺存储+军事通信需求（光纤链） |
| 策略 | **当前操作重点** — 博主明确指示现阶段聚焦此方向 |
| 代表标的 | 拓荆科技（薄膜沉积）、北方华创（刻蚀）、盛美上海（清洗）、华海清科（CMP）、永鼎股份（光纤+光芯片双逻辑）、杭电股份（光纤） |

**博主判断**：第三梯队两大逻辑叠加——

1. **存储设备链**：长鑫存储和长存即将IPO，融资额60-70%用于购买设备。设备中薄膜沉积确定性最高（技术壁垒最高/国产替代空间最大），其次清洗设备、光刻胶。存储芯片本身也受益于全球缺存储格局，走得更长。

2. **光纤光缆链**：不光是AI逻辑——AI数据中心对超低损耗光纤的需求持续增长——还有战争逻辑（军事通信对光纤光缆的刚性需求）。双重逻辑提供更强的安全边际。

## 梯队切换逻辑

博主强调这不是静态划分，而是根据市场节奏动态调整：

```
第一梯队涨太多、需要消化 → 切换到第三梯队
第一梯队回调到位、安全边际出现 → 重新介入第一梯队
第二梯队 = 中间地带，等第一梯队稳定后同步布局
```

切换的触发条件：
- 价格位置（涨了多久、涨了多少）
- 催化节奏（哪些方向有新的催化剂）
- 安全边际（调整是否充分）
- 外部环境（美股AI链走势、地缘风险）

## 与时序操作的配合

博主在06-17晚间明确提出两条交易纪律：

- **确定性品种**：慢就是快。产业逻辑确定的标的（如存储设备链），不需要追求短期弹性，耐心持有等待逻辑兑现。
- **弹性品种**：快也是慢。高弹性方向（如参股链/情绪票），进出要快，不能恋战。追涨杀跌反而会慢。

这呼应了博主一贯的框架：不同周期不同打法。[[情绪周期与操作节奏]]中"不同周期不混用"的原则在此具体化为"不同梯队不同节奏"。

---

## 与中报期的关系

中报切换期（6/17→7/15）为梯队选择增加了业绩过滤层：
- 第三梯队中的存储设备：中报期可能因为订单确认节奏偏慢而表现不及预期，但产业逻辑不变
- 第三梯队中的存储芯片：受益于涨价周期，中报有望超预期
- 第一梯队PCB/光模块：中报大概率兑现，但股价已提前反映

博主的隐含判断：**中报期第三梯队反而性价比更高**，因为第一梯队利好可能已被定价。
